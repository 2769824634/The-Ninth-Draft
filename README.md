# THE NINTH DRAFT · 第九稿

一座冷战风格的解密档案馆。网站默认英文，右上角 `EN / 中` 可以切换中文（按 `L` 也行）；本说明为中文。

## 世界观：霏微

档案馆属于 **Gerimis / 霏微**（马来语「细雨」）：一座海峡里的小岛，时间永远停在 1999 年。岛上有一个 **记录署 / Records Office**，负责把发生过的事整理成最终版本（第九稿）。但被划掉的旧稿不会消失，它们会悄悄漏回现实，叫做 **回流 / Backflow**：填掉的海重新露出来，拆掉的老村一夜亮灯，路牌挂回旧名，被「修订出去」的人又走回街上。

> 本岛一切如常。如有不同，以现场为准。

地理照 1999 年的新加坡，人物和机构全部虚构。全岛按当年的规划区分成 **52 个区**（35 个住人，其余是公园、水库、工业区、小岛，军事用地在地图上留白「未测绘」），名字用当地真名，带政治人物名字的地名换成当地旧名或邻近地名。核心区仍叫 **中枢 Axis**，记录署就在这里。全部区的数据（片区、交通、旧貌）在 `src/data/gerimis/districts.ts`，写法和取名的规矩在项目文件 `ideas/霏微-地名录.md`。

原来的七个区改成了真名，旧代号照样能用（档案、网址、访客登记都会自动换成新名）：

| --- | --- | --- |
| 中枢 Axis | 中枢 Axis | `axis` |
| 红桥 Pons Ruber | 宏茂桥 Ang Mo Kio | `ang-mo-kio` |
| 大泽 Palus Magna | 大巴窑 Toa Payoh | `toa-payoh` |
| 红丘 Collis Ruber | 红山 Bukit Merah | `bukit-merah` |

1999 年以后才拆掉的东西，岛上还在；1999 年以前就没了的，地图上用红铅笔淡淡画出来，是回流的种子。

档案由作者和朋友们一起写，中文或英文都可以；写作须知、红线和交稿格式见项目文件里的「入馆须知」。一个不明说的约定：回流事件的日期尽量落在某月 9 号。

访问者走进一间档案室：柚木地板、钢制档案柜、黄铜吊灯，用长焦镜头斜着拍。拉开一个柜子，抽屉滑出来，里面挂着一排档案；抽一份出来，可以就站在柜子前翻看，也可以拿到窗下的阅档桌上，几份并排摊着对照。档案正文摊成一张打字机风格的纸，房间就在纸后面，不换地方。太空元素只作为风格出现：轨道线、星图坐标、档案馆徽章上的卫星，不限定内容题材。

视觉与交互参考了《明日方舟》「莱茵生命：访问」的档案终端（[RhineLabUI](https://github.com/LBEILC/RhineLabUI) / [Rhine-Music-Demo](https://github.com/RonaldDeng/Rhine-Music-Demo)）和 [OHM TAPE](https://github.com/zcy83821448/cassette) 的「没有硬切」原则。代码、模型、贴图、音效全部为本项目原创，场景完全程序化生成，没有使用外部模型或图片。

## 功能

- **档案库**（整个档案室就是这一间房）：一间完整的剖面模型，和资料室、办公室同一种画法，但更沉：柚木长条地板、齐肩高的柚木护墙板、黄铜挂镜线，黄铜配乳白肋纹玻璃的吊灯。进门是门垫、四个电灯开关和铜牌，左边是索引卡柜，左墙一排钢制档案柜放正式档案（人员、事件、计划各一组），中间两排背靠背的柜子放各区的例行文件，窗下是阅档桌，入库台对着门，后墙有全岛地图和拉着红绳的绝密柜。房间不会在读档案时消失：纸就摊在房间前面
  - **灯**：门边四个开关各管一排吊灯（门口、正式档案、例行文件、阅档桌和入库台），房间里点开关或左栏的四个按钮都行，灯泡亮起前会闪两下。阅档桌两盏台灯和入库台的台灯点一下就拉灯绳。夜里默认只开门口、正式档案和阅档那几排，例行文件那边是暗的；你调过的灯记到岛上下一个 7 点或 19 点
  - **天气**：按岛上的日期算，同一天所有人看到的一样（年底季风时更容易下雨）。下雨天百叶窗上是雨痕，有雨声，门口撑开一把晾着的红伞、地上一摊水，湿度表往上走，除湿机的灯变红，点它把水箱倒掉。白天窗格光斑跟着岛上的钟在地上挪，傍晚发橙；夜里窗外是路灯的蓝光。想看另一种天气，网址后加 `?weather=rain` 或 `?weather=dry`
  - **其他能点的**：索引卡柜打开索引检索；入库台的「今日入库」托盘列出今天到的档案；绝密柜列出 TOP SECRET 档案；例行文件柜说明正在上架。挂钟走的是岛上时间
- **拉开柜子**：点一组正式档案柜（或左栏的「人员 / 事件 / 计划」），镜头走到柜子前，抽屉滑出来，里面一排档案立着：人员是马尼拉夹，事件是牛皮纸袋，计划是灰纸板，TOP SECRET 是绕线袋，每份档案的标签上印着编号和一道密级色。右边同时列出这个抽屉里的档案。`← →` 换抽屉（翻到头接下一组柜子），`↑ ↓` 在抽屉里挑，Esc 关上抽屉
- **翻看还是拿走**：点一份档案，它半抽出来，问你两件事——「就地翻看」就站在柜子前读（Enter），「拿到桌上」把它放到阅档桌（`T`）。读完 Esc，它回到原位
- **阅档桌**：桌上最多摊六份，面朝上，封面印着编号、标题和密级章。点桌上一份就读它；读的时候纸下面列出桌上其他几份，点「并排」把另一份摊到右边对照着看，点「换到前面读」掉个个儿。正文里提到的档案如果也在桌上，小便条上直接是「摆到旁边对照」，不在桌上就写它在哪个抽屉。被拿走的档案，抽屉里原位留一张红色的 OUT 卡。桌上摊着什么只存在你自己的浏览器里，可以一份份还回去，也可以「全部放回抽屉」
- **索引卡柜**：门边的卡柜抽屉拉开，卡片一张一张翻（`← →`，手机上左右划）。按编号、按区、按年份三种排法，每一组前面立一张导片。卡片上写着档案的区、日期、地点、密级，和它存放的抽屉夹号；点「去柜子拿」，镜头就走到那个柜子把抽屉拉开
- **档案详情**：正文摊成一张纸，居中一页读完：摘要、正文、附件依次往下排，不分栏目；房间留在纸后面，暗一层但不消失
- **涂黑文字**：正文里 `||这样写||` 会显示为黑条，鼠标悬停或点按后显示
- **关联档案**：`related` 字段自动生成双向「另见」，排在纸的最后一行；正文里写到的档案编号（如 E-0001）会自动变成引用记号，点开先出一张小便条（编号、标题、摘要），再决定要不要调出来。还没到日期的档案，编号只显示「还没归档」
- **原地读**：档案只在档案室里读。资料室、办公室和其他页面上点到档案，原地出一张调阅单：编号、密级、摘由、存放位置（如「档案库 · 第 02 抽屉 · 第 01 夹」），想看全文再点「去档案室调阅」，到了档案室镜头会走到那个柜子、拉开抽屉、把那份抽出来；看完按 Esc 回到原来的地方
- **线索墙**（第二个房间，`/wall/`）：所有档案以卡片钉在软木板上，红线直接来自 `related` 字段，不用多写任何东西。按 `W` 或点档案室页头的 Links 进入（只在档案室里显示，之后并进办公室），档案纸面最后一行也可以「Show on the link wall」。鼠标停在卡片上只显示它的联系；卡片可以拖动，红线会下垂摆动；点击卡片回到档案室打开它。滚轮缩放，拖动空白处平移，`← →` 轮流聚焦，Reset wall 恢复原来的排布。拖过的位置只保存在你自己的浏览器里
- **战术层**（线索墙上）：软木板上印着地图网格（列 A、B、C…，行 01、02…），每张卡片左下角有目标框、威胁等级（按密级 0–4 个菱形）和联系数 `LNK`。一道扫描带定时从左扫到右，扫过的卡片会亮一下；聚焦的卡片四角出现锁定框。鼠标在板上移动时，页脚的天文坐标换成板面坐标和网格编号，左侧说明也会标出卡片所在格。这些都从现有字段自动生成。系统开启「减少动态效果」时不扫描
- **调取条**：每次打开档案，详情栏顶部先出现一条 ARCHIVIST 的调取进度（抽屉号、档案位置、分段进度条），下面附一句提示或吐槽。详情栏的内容跟着进度条自上而下显现，一条细扫描线压在显现的位置上：进度到多少，内容就显示多少。加载完后调取条自动收起。档案里有 Heuss 批注时，提示会告诉你批注在第几稿
- **从别的房间打开**：调阅单上点「去档案室调阅」会记住你从哪来，读完按 Esc 或左上角的返回，转场回到原来的房间
- **导航**：页头只有三间房加地图（档案室、资料室、办公室、地图），入馆登记和入馆须知在右上角。日报在资料室报刊架上（「今天的报纸」或任意一根报杆），年历就是办公室告示板旁的挂历；旧网址 `/daily/`、`/daily/1999-03-09/` 会带到资料室并把那天的报纸摊开，`/calendar/` 带到办公室墙上的挂历（`/office/#calendar-1999-03-09` 直接翻到那个月、钉出那天的纸条）
- **旧稿**：有修订标记的档案，旧稿压在定稿下面，纸的右边露出几张旧稿的边（手机上排在纸的上方）。只放档案 `drafts` 里写到、而且日期已经到了的那几稿；没写 `drafts` 时按修订标记自动挑出有改动的稿。抽出一张，纸变成那一稿的样子，盖上 SUPERSEDED 章：这一稿新加的句子用红笔圈出，后来被改掉的用红色虚线框出，自动滚到改动处。键盘 `[` `]` 也能翻
- **Heuss 批注怎么找**：哪张旧稿的页边有 Heuss 的批注，它的边上就有一个蓝点；调取条的提示也会说批注在第几稿
- **SYSTEM 提示**：除了 ARCHIVIST，档案馆还有一个冷冰冰的机器声音 SYSTEM。翻阅档案、揭开涂黑、翻回早期稿、进入线索墙时，它偶尔会在屏幕顶部弹出一句提示（如 "Access logged."），开着声音时用合成女声读出来。密级越高越容易出现，两次之间至少隔 25 秒。台词在 `src/data/system.json`
- **开机音效**：第一次进入时点 Enter，会听到继电器咔哒、电源嗡鸣升起和两声提示音，SYSTEM 报一句 "Terminal online"。同一次浏览里再刷新页面，第一次点击时会播放一段短的开机声
- **附件**：纸面最下面是夹在档案上的纸片，点一下可以拿起来看。每份档案都自动带一张传阅单（Routing slip），内容来自 `drafts` 和 `related`；想多夹东西就写可选的 `attachments` 字段（写法见下文）
- **绕线档案袋**：密级为 TOP SECRET 的档案在抽屉里不是马尼拉档案夹，而是牛皮纸绕线档案袋：封舌上一颗纤维扣，袋身一颗，棉线 8 字形绕在两颗扣上。打开时线一圈圈松开（扣跟着转，线头垂下），封舌掀起，档案从袋口抽出来平放在袋上；合上时整段倒放，线重新绕回去。按现有的 `stamp` 自动判断，不用另外标记
- **套色网点照片**：档案的 `image` 照片会在浏览器里自动转成网点，用黑、红两色套印，红版故意错开一点。3D 档案夹内页、详情栏 Overview 和线索墙卡片上都用这张网点照片。没有照片的人员档案会显示一张代码生成的网点剪影（每个编号的剪影都不一样），说明文字写 "No photograph on file · Composite"；有照片时显示 `imageCaption`
- **Programs 章节页**：每次访问第一次打开 Programs 抽屉时，会先闪过一张构成主义风格的章节页（斜向红块、黑色楔形、超宽小写标题、徽章、档案数量和年份范围），约两秒后自动消失，点击或按任意键可以跳过。NASA 蓝只在这里出现
- **光圈转场**：两个房间之间用相机光圈切换，六片叶片收拢再张开；系统开启「减少动态效果」时改为淡入淡出
- **检索**：按 `/` 打开全文检索，可以搜索标题、编号、字段和正文
- **昼 / 夜**：白天是灰白档案室；夜晚只有一盏台灯照着当前档案，切换时颜色平滑过渡
- **验档灯：色温跟着密级走**：吊灯永远是暖黄的钨丝灯，不变色。每个阅读位置（每组柜子侧面、阅档桌上）另有一根日光灯管「验档灯」，记录署规定密级越高越要在冷光下看（涂改和刮掉的字冷光下才看得出）：DECLASSIFIED、RESTRICTED 不开，CONFIDENTIAL 半亮，SECRET 大半，TOP SECRET 全亮，起辉时闪几下、带嗡声。色温是灯管和暖灯真实混出来的。摊开的纸面上的光每一帧按读的位置实际照到的灯、天光、月光、路灯算出来，光斑方向跟着灯走；读的时候纸左边有「这里的灯」开关，关掉就看着纸暗下去换成月光或路灯。印章、标签的密级颜色不变
- **灯全关了还能读**：夜里把开关和台灯都关掉，纸上只剩窗外的光。月亮按 1999 年那一天真实的月相算，满月亮、新月没有，下雨的夜里也没有；没有月亮就只剩路灯（钠灯的橙黄）。这时纸是冷蓝或橙黄的，暗一层，顶上写一句「灯关着。这页是月光照的。」字始终看得清
- **声音**：没有一直响的底噪，房间里的声音来自看得见的东西（档案室：落地扇的风、除湿机隔几分钟启动一阵、干燥天窗外偶尔有车开过、下雨天的雨声；门边开关栏和桌上「这里的灯」里都有「物件声」开关，只关风扇、除湿机和车声，记在本机）；纸张、抽屉、盖章、打字等音效；切换抽屉时有调频杂音，Programs 抽屉里能听到 Sputnik 的「哔—哔—」；每隔一两分钟，远处的数字电台会放一段旋律，再报一组数字。全部实时合成，可以随时关闭
- **中英切换**：右上角 `EN / 中` 或按 `L`。界面、ARCHIVIST、SYSTEM 全部双语，中文模式下 SYSTEM 用中文女声朗读；3D 档案夹封面和内页、线索墙卡片也会重新打字。印章、档案编号、口令保持英文。选择会被记住，默认英文。切换时淡出淡入，没有硬切
- **基线测试**（`/baseline/`）：致敬《银翼杀手 2049》开头的复述测试，台词全部原创。一间白色的平面隔间（照原片：只有声音的审讯、旁边一台虹膜扫描仪、底部一条脉搏线），不用 3D。SYSTEM 念一句、你点选或按 1/2/3 原样复述，共九句、每句十秒；答过的词留在隔间里，答偏的被红线划掉。偏差越大，整页越波动（SVG 位移滤镜、色散），瞳孔放大、脉搏变红；判成「偏差」时接 1900 倒回闪回。**隐藏触发**：九句没有一句照原样复述，会在闪回后黑屏，被请到 `/exit/`——纯黑一页，只有一句话（「本稿无此人。」/ "No such person in this draft."），句末的句号是回档案馆的链接。结果分稳定 / 偏移 / 偏差三档，只存在本机，显示在「我家」。减少动态效果时不波动不抖动
- **入馆登记**（`/register/`，右上角 Sign in）：门口的访客簿。前面几行是当天来过的人（按岛上日期生成，谁看都一样），最后一行写你的名字和「从哪来」（选填），签名后门口给一张阅览证（`RC-` 开头，有效到 31.12.99），资料室借书单上写你的名字。不签也能读。下面问「想在岛上住下？」，带到三号窗口
- **居民登记**（`/register/resident/`，RO-9 表）：填代号、出生日期（日-月-年三格）、性别（男 M / 女 F），再勾一项「在本岛出生 / 通常居于本岛，自 ____ 年起 / 新抵岛人士」。新抵岛的先在渡轮码头填入境卡（盖 LANDED、撕下存根）；然后在机器上取号、看叫号牌，三号窗口叫到你，办事员按你勾的那一项说话。分屋子：通常居住和新抵岛的先选一片、再在街道图上点区，摇签筒抽一座组屋（Blk、楼层、门牌，按代号确定）；本岛出生的不抽签，在地名索引里找小时候住的那一座（邮编、「Blk 7 Lorong 7 Toa Payoh」、「大巴窑 7 座」都能搜，也能直接点地图上的楼），自己选楼层和门，按旧址补发。最后核对、归档、过塑，拿到身份证、钥匙和六个英文单词的恢复口令。身份证正面印姓名、出生日期、性别、代码行（`G` / `R87` / `N`）和出生地，背面印住址、签发日期。三种人的证用三种卡：本岛出生砖红奶油底、圆角带团花；通常居住墨绿灰绿底、照片在右、年份淡印在底纹里；新抵岛赭黄米黄底、方格直角、打了孔（样式在 `src/styles/idcard.css` 的 `.idc--G / --R / --N`）。勾选项和代码是岛上自己的写法，不对应现实里任何身份或居留资格。全部只存在访客自己的浏览器里；换设备时输入代号、口令和出生日期找回同一间屋子（出生日期不在口令里，只拿来核对，填错就打不开）。旧的四个词口令照样能用
- **我家**（`/me/`，原「我的档案」）：门牌、住址、邮编，证上代码，同一层八个信箱（左邻右舍的名字按邮编和门牌生成，谁看都一样；你那格里有两三封寄给前任住户的信，点开能读；本岛出生的有一张多年前寄给你的明信片），「楼下」一栏：每次回家碰到一个常露面的人或一件小事（看岛上几点、你回来过几次、隔了多久，只记在本机，`src/app/visitor/encounters.ts`），和这座楼楼下的告示板（邻居的启事、管理处通知，每周换），街道图上你那座楼和楼下的设施，**日记**（床边的抽屉，只存在这台设备上，谁都看不到；写下的内容听起来真的很难过时，旁边会出现一张平常话写的求助便条：新加坡援人协会 1767、WhatsApp 9151 1767、findahelpline.com，检测只在本机做），恢复口令。右边是能翻面的身份证和钥匙牌。第一次打开时，档案装在封口的牛皮纸绕线档案袋里送来：绕着下面那颗扣转圈解线（也可以点「帮我绕开」）；页尾「重新封上」可以再看一遍。改版之前登记过的人还在，档案页上有一节「欠你一间屋子」，按新抵岛人士在原来的区补抽一次，档案编号和口令随之换新；他们当年没填出生日期和性别，证上印 NOT DECLARED。「小秘密」已取消
- **霏微地图**（`/map/`）：一本 1999 年的街道图，能拖、能两指或滚轮缩放。形状参考 OpenStreetMap，重画成我们自己的线条，再按 1999 年改回去（之后才填的海、才挖的水库、才修的路和组屋都拿掉；地铁只有南北线、东西线，武吉班让轻轨 11 月 6 日以前是虚线，东北线画成在挖）。远看是 52 个区，近一点是地铁站和镇名，再近是路名，最近是一座座组屋和座号。全岛按街道图分页（每页 A–D × 1–4 小格），左上角显示指着的页码和区；点区出卡片，能跳到区页；放到最近点一座组屋，出一张地址小纸条（座号、街名、六位邮编「霏微 550007」、建成年份和层数）。近看还有生活设施，照测绘图印成小方框加缩写：巴刹和熟食中心（MKT / 市）、巴士转换站（黑底 BUS / 站）、商场、邮局、综合诊疗所、医院、民众联络所、图书馆、游泳池、学校、宗教场所、渡轮码头，1999 年以前关了的用红铅笔虚线框；点开出小纸条（名字、地址、邮编、开业年份、营业时间），组屋的纸条写「楼下：……」。学校名字是虚构的，宗教场所只写外观。红色虚线是填海以前的海岸，斜线是未测绘的军事用地。档案按 `district` 字段自动钉上去，写了座号或片区的，近看钉在那一座、那一片上，访客住的区会亮。地图下面是**地名索引**：街道图后面那几十页，图上每条路、每个车站、每条河和地名按字母排，带页码和格号，点一行图就翻过去；查找框里写「Blk 7 Serangoon」「实龙岗 7 座」或邮编，能找到那一座组屋和楼下的设施；也能按「区 + 类别」查，如「宏茂桥 巴刹」「Toa Payoh post office」。邮编照新加坡的规矩编（两位邮区 + 一位小区 + 三位座号），OpenStreetMap 里有的照用，没有的按同一条街推出来。数据由 `scripts/map/` 的脚本生成，说明和出处在 `scripts/map/README.md`
- **区页**（`/district/<代号>/`）：每个区一页，有本区放大的街道图（区外淡掉）、片区、交通、在这个区归档的档案、本地时钟（岛上时间加上本区的时差）、旧地图上有什么、附近的区。旧代号的网址（如 `/district/pons-ruber/`）会带到新页
- **入馆须知**（`/guide/`）：告诉第一次来的人这里是哪里、能做什么
- **小巧思**（不上锁，到处点点就能碰到，代码在 `src/app/ui/quirks.ts`）：

  - 左下角 ARCHIVIST 那行字可以戳，连戳五下它会生气

## 添加 / 修改档案

每份档案是 `src/content/records/` 下的一个 Markdown 文件，子文件夹只是为了方便整理：

```markdown
---
file: "P-0005"                 # 档案编号，必须唯一
category: personnel            # personnel 人员 / events 事件 / programs 计划
title: "Full Name"
subtitle: "Role or alias"
stamp: "SECRET"                # TOP SECRET / SECRET / CONFIDENTIAL / RESTRICTED / DECLASSIFIED
status: "On duty"
date: "1971 –"
place: "Toa Payoh, Kim Keat"   # 读者看到的地名
district: toa-payoh            # 可选，地区代号（全部代号在 src/data/gerimis/districts.ts），地图、区页和访客秘密会用到
block: "Blk 7 Lorong Lew Lian"  # 可选，区里的组屋座号（"Blk 7"、"7 座"，后面可加街名）或片区（照区页上「片区」的写法，如 "Kim Keat"），地图近看会钉到那一座 / 那一片，区页写出门牌和邮编。不写时会从 place 里找「Block 7」「7 座」或片区名
image: "records/p-0005.jpg"    # 可选，图片放在 public/records/ 下
fields:
  - label: "Role"
    value: "Ferry pilot"
summary: "Overview 栏的摘要，可以用 ||涂黑||。"
related: ["P-0001", "E-0002"]  # 关联档案的编号
tags: ["ferry"]
order: 5                       # 在同一类别里的排序
---

Record 栏的正文，标准 Markdown，同样支持 ||涂黑||。
```

保存后，开发模式下页面会自动刷新；推送到 `main` 后会自动部署。

### 修订痕迹（第九稿）

在 `summary`、`fields` 的值或正文里加修订标记，档案下面就会压上旧稿（纸面右边露出的那几张）。稿号 1–8 是旧稿，第 9 稿就是你写的定稿（界面上只叫「定稿」）；没有任何标记的档案没有旧稿。抽出旧稿时，3D 档案夹封面和内页上的印章也会换成那一稿的密级。`drafts` 里写了日期的稿，日期到了才会出现。

| 写法 | 效果 |
| --- | --- |
| `[[+5: 文字]]` | 第 5 稿新加入（那一稿用红笔圈出），之前的稿里不存在 |
| `[[-6: 文字]]` | 第 6 稿被红线划掉，之后消失 |
| `[[#3-7: 文字]]` | 第 3–7 稿被涂黑；只写一个数字（如 `[[#3: …]]`）表示从第 3 稿起一直涂黑 |
| `[[note 4-6: 文字]]` | 第 4–6 稿出现手写批注，自动署名 **— Heuss**；只写一个数字表示仅那一稿 |
| `\|\|文字\|\|` | 定稿中的涂黑，读者悬停或点按可以揭开 |

每一稿的标签、日期、经手人和印章可以在 frontmatter 里写（可选，不写就用默认值）：

```yaml
drafts:
  - n: 1
    label: "Field notes"
    date: "1959-11-04"
    by: "A. Reiss"
    stamp: "DRAFT"        # DRAFT / TOP SECRET / SECRET / CONFIDENTIAL / RESTRICTED / DECLASSIFIED
  - n: 5
    label: "Amended"
    by: "Heuss"
    stamp: "TOP SECRET"
```

滑到哪一稿，界面颜色就跟着那一稿的密级变化。

### 附件（可选）

每份档案都会自动生成一张传阅单，不用写任何东西。想在档案上多夹几样东西，就在 frontmatter 里加 `attachments`：

```yaml
attachments:
  - "直接写一句话，就是一张 Heuss 署名的便条。"
  - kind: telegram          # 电报：自动大写，句号变成 STOP
    title: "Halden to Oslo"  # 发报路线
    date: "1959-11-03"
    text: "Carrier steady on 4.625. Request instructions."
  - kind: ticket            # 票根：title 是票名，自动生成编号
    title: "Coastal Steamer"
    text: "Tromsø to Hammerfest, deck passage"
    date: "1958-02-14"
  - kind: clipping          # 剪报：title 是标题
    title: "Mapmaker returns from the ice"
    text: "正文里也可以用 ||涂黑||。"
  - kind: negative          # 底片条：用档案照片（没有照片就用剪影）自动生成三格负片
    text: "说明文字"
    draft: 4                # 可选：从第 4 稿起才夹进档案，抽出更早的旧稿时会消失
  - kind: note
    text: "便条也可以换署名。"
    by: "Morozov"
```

`kind` 可选 `note`（便条，默认）、`telegram`、`ticket`、`clipping`、`negative`。所有文字照例写英文。

| 密级 | 颜色 |

### ARCHIVIST（档案馆管理员）

页面左下角的那行话来自 `src/data/archivist.json`。每类事件（欢迎、开抽屉、打开某个密级的档案、翻回早期稿、揭开涂黑、检索无结果、发呆太久、进出线索墙、调取档案时的提示 `retrieve`、线索墙扫描 `sweep` 等）都是一组台词，随机挑一句说。`{title}`、`{file}`、`{draft}` 会自动替换成当前的档案标题、编号和稿号。想加多少句都行。

## 中文版

### 给档案加中文版（可选）

在英文档案旁边放一个同名的 `*.zh.md`，例如 `personnel/p-0002.md` 旁边放 `personnel/p-0002.zh.md`。没有中文版的档案在中文模式下照常显示英文原文，不会出错。

朋友交来的稿子可以是中文也可以是英文。网站仍以 `.md` 为主文件、默认显示英文，所以中文写成的稿子由我们补一份英文 `.md`，中文原文放进 `.zh.md`。

```markdown
---
file: "P-0002"            # 必填，对应英文档案的编号
title: "Heuss"
subtitle: "记录署数据组技术员"
summary: "……"
fields:
  - label: "职务"
    value: "数据组技术员，年份字段整改"
---

正文（修订标记、涂黑、批注的写法和英文完全一样）
```

- 除 `file` 外全部可选：`title`、`subtitle`、`status`、`date`、`place`、`imageCaption`、`fields`、`summary`、`tags`、`drafts`、`attachments`。没写的字段沿用英文。
- `drafts` 只需写 `n` 和要翻译的 `label` / `by`；`attachments` 按顺序对应英文的附件，可以只写文字（字符串）或 `{title, text, date, by}`。
- 密级、照片、`related`、印章、编号都跟英文档案共用，不用重复写。
- 检索同时索引中英两种文字，用哪种语言都能搜到。

### 翻译的语气

中文要像中文，不要翻译腔。可以比英文更幽默、诙谐，甚至带点讽刺，但不能偏离原意。ARCHIVIST 可以更损一点；SYSTEM 照样冷淡、简短、从不开玩笑。

### 台词与界面文字

| 文件 | 内容 |
| --- | --- |
| `src/data/ui.zh.json` | 界面文字，以英文原文为键，`{n}` 之类的变量照写 |
| `src/data/archivist.zh.json` | ARCHIVIST 中文台词，分组和英文相同 |
| `src/data/system.zh.json` | SYSTEM 中文台词 |

字典里没有的界面文字会显示英文，所以漏翻不会坏，只会露馅。

### 字体（「机械铭牌」）

| 用途 | 字体 |
| --- | --- |
| 大标题 | 站酷酷黑 |
| 正文 | 寒蝉活宋体·復 |
| 标签、小字 | 寒蝉德黑·窄（粗体作标题后备） |
| SYSTEM 提示 | 寒蝉点阵体 |
| Heuss 批注 | 汇文仿宋 |

母本放在 `fonts-src/zh/`（已裁到 GB2312 范围）。`npm run build` 时 `integrations/zh-fonts.mjs` 会数一遍输出里实际用到的汉字，按用得多少排序后**切块**：最常用的约 600 字一块，往后每 200 字一块，每种字体都切成同样的几块，放到 `dist/fonts/zh/`，规则写在 `faces.css`。每块用 `unicode-range` 声明，浏览器只下载当前页面真正用到的那几块：只看英文的访客几乎不下载中文字体，书里的生僻字也只在翻到那一页时才下载。块的文件名带内容哈希，换了内容不会读到旧缓存。加了新的中文档案或书不用做任何事，下次构建会自动重新切；只有用到 GB2312 以外的生僻字时才需要换母本。画在 3D 场景里（canvas）的中文不会自己触发下载，场景代码画字前要先调 `canvasFontsReady(文字)`。

许可：寒蝉系列为 SIL OFL；站酷酷黑免费商用；汇文仿宋免费商用、不得单独售卖字体。

### 霏微日报

岛上的报纸在资料室读：从报刊架抽下一根报杆（一个月一根），报杆留在架上，这个月的报纸拿到阅览桌上，先翻本月目录挑一天（也可以逐期往后翻），点「展开这一期」才铺开四版，对折线、新闻纸色；「折起来」回到目录，再按 Esc 挂回报架。从「今天的报纸」或旧网址进来的直接摊开那一天。**不用另外写**，构建时从档案自动排版，一期四版：

- 第 1 版 头版：报头（天气、报价两只耳朵）、期号、头条（标题、副题、网点新闻照片、正文）、第二条新闻、今日要目、记录署一句话
- 第 2 版 本岛新闻：图片新闻、剪报文章、各区简讯、巴士改道、天气
- 第 3 版 公告与来信：更正、档案摘录、记录署公告、读者来信、本周活动
- 第 4 版 分类广告：小广告、潮汐与钟点、今晚电视

能翻版（← → 键、版面按钮、手机上左右滑），「前一天 / 后一天」换日子，「本月往期」按日期抽，跨月会自动换一根报杆。岛上今天之后的报纸还没付印，未到月份的报杆也不挂出来。

报纸内容从哪里来：

- 有日期的事件、计划 → 当天的头版
- `kind: clipping` 的附件 → 当天报纸上的一篇文章（标题写成 `Gerimis Daily · page 6` 会标出版面）
- 有日期的修订稿 → 「更正」栏（报纸上的更正，就是档案的修订）
- 其他带日期的附件 → 「档案摘录」
- 新闻照片：档案有 `image` 就用它（自动套色网点），没有就按日期画一张街景（组屋、巴士、雨树、雨）
- 平常日子的新闻、各区简讯、巴士改道、读者来信、本周活动、天气、分类广告、潮汐、电视节目，按日期从 `src/lib/daily.ts` 里固定的题库挑，同一天永远印同样的内容；题库可以随时往里加

报纸只印官方版本：被划掉的句子、Heuss 的批注都不会上报，涂黑的地方也揭不开。12 月 31 日那一期永远会出。

### 资料室（第三个房间）

`/library/` 是记录署的阅览室，做成一个**剖面模型**放在纸面上：揭掉两面墙和屋顶，镜头和档案室一样是斜俯视的长焦。白天日光从后墙的拱窗斜射进来，在地板上投出窗格光斑，光柱里有浮尘；夜里窗外的组屋亮灯，阅览桌上方的乳白玻璃球吊灯亮起。黄铜、清漆会反射环境光。

房间里有四个角落，`0–4` 或左栏切换，点模型里的东西也能过去：

- **报刊架**：《霏微日报》一个月一根报杆。1999 年每天都有一期，有档案事件的日子是新闻，其余是平常日子。取下报杆，在桌上挑一期摊开（见上面「霏微日报」）
- **书墙**：左墙通高书架。登记过的书按书号散在整面墙上，区志在够不着的高层，一个大区一册（中区、东区、北区、东北区、西区），每个区一章：片区、交通、以前有什么、本区大事记（区志是公开出版物，不列档案编号）。在左栏点书（或把鼠标移上去），镜头会沿着书墙走到它面前；取高层的书时，移动书梯会先沿轨道滚过去
- **目录卡片柜**：一份档案一张卡。拉开抽屉，右边列出卡片，点卡片出一张调阅单（摘由和存放位置），要看全文再自己去档案室调；空抽屉留给还没进来的档案
- **借还台**：柜台取阅的入馆须知；你的借书记录，可以在借书卡上盖今天的日期

取书按人的节奏来：手指先把书顶勾出来，书被慢慢抽出，左右两本书歪向空位；拿到眼前，先看书脊，再转过来看封面，确认是要的那一本；高层的书随人从梯子上下来；然后拿着走到阅览桌（按距离算，约每秒 1.5 米，手里的书随步子轻轻起伏），放平、落到桌上，最后翻开封面，右边出现阅读栏。镜头一路跟着书，夜里那盏暖光也跟着书走。整段 7–10 秒，进行中点一下画面会加速；放回去是倒放，快一些。

**书的厚度跟着页数走**：内容少的是骑马钉小册子，档案多了下次构建自动变厚。书全部从现有内容自动装订（`src/lib/library.ts`），场景在 `src/app/library/`。

**画质**：默认全开（每本书都投影、4096 阴影贴图、吊灯白天也亮、光柱和浮尘）。页面开头会测帧率，只有设备跟不上时才一级一级往下降（先降分辨率，再关书的投影，最后关吊灯实时光和光柱），不会再升回去，免得画面闪。网址后面加 `?perf` 显示帧率、当前档位和显卡型号；加 `?full` 锁定全画质，不自动降级。

### 资料室的书（公版书）

书放在 `src/content/books/`，**一本书一个 `.md` 文件**，照原文的语言放（中文书就是中文，英文书就是英文），只放版权已过期的书：

```markdown
---
title: 朝花夕拾
titleAlt: Dawn Blossoms Plucked at Dusk   # 另一种语言的书名，书脊和卡片用
author: 鲁迅
authorAlt: Lu Xun
year: '1928'
lang: zh            # zh 或 en
source: 维基文库    # 底本从哪来，印在扉页上
order: 10           # 越小越靠前（可选）
---

## 小引

正文……

## 狗·猫·鼠

正文……
```

- `## ` 是章节标题，自动生成目录，点目录直接翻到那一章；太长的章自动切成几页（中文约 900 字一页，英文约 2200 字）
- 书的厚度跟页数走，散放在书墙中间几层；封面印「公版 · 年份」，不印记录署
- 正文另存成 `library/books/<文件名>.json`，取书时才下载，所以书再多也不拖慢资料室；生僻字所在的字体块也是翻到那页才下载

### 办公室

`/office/` 是记录署地下一层数据组的办公室，Heuss 上班的地方，也是第四间 3D 房间。画面语言和另外三间一样：纸上的剖面模型、斜俯视长焦、左栏 + 页脚。窗户开在人行道高度，白天百叶窗把阳光切成一条条落在地上，晚上外面是路灯和雨，屋里只剩台灯、落地灯和屏幕的琥珀光。挂钟按真实时间走，告示板上钉着最新的五起回流事件。

**挂历**：署里自己印的 1999 年挂历，一月一张，上半张是网点照片，下半张是日子（中文模式下日子底下印农历和节日）。**不用另外写**，构建时从档案里读日期：事件档案的日子被 Heuss 用红笔圈起来，其余带日期的档案、旧稿、附件打个铅笔勾；这个月过去的日子用铅笔划掉，今天套着红色塑料日期框；每个 9 号有个小红点。点挂历凑近看，点图片或按 ← → 翻月份（纸往上掀，往回翻是上一张落下来），点日子在挂历下面钉一张纸条：那天归档的东西（点编号出调阅单），和那天的《霏微日报》在资料室哪根报杆上。岛上今天之后的日子还没有东西。

`0–4` 或左栏切换角落：整间办公室、办公桌和电脑、沙发、告示板、磁带机。点模型里的东西也会推近，`Esc` 拉回全景，方向键轮换。

- **办公桌**：一台 CRT 台式机，屏幕是真正的网页，贴在 3D 显示器上，可以直接点、直接打字。`F1–F5` 切换程序：
  - **F1 终端**：`HELP`、`LS`、`OPEN E-0004`、`DIFF E-0004 3`、`LOG`、`YEAR`、`ROLLOVER`、`CLOCK`、`SYNC`、`WHO`、`CLEAR`、`LOGOUT`（屏幕熄灭，镜头退回全景）
  - **F2 日志**：全岛所有带日期的修订记录，点一行调出档案
  - **F3 年份**：`YEAR: 99`。「跨年测试」会跳到 00、被读成 1900、整屏乱码，然后自动回滚（接 R-0001）
  - **F4 时钟**：七个区的钟（中枢、宏茂桥、大巴窑、红山、后港、兀兰、实龙岗），兀兰快一小时、后港慢一小时，同步后又滑回去（接 R-0003）
  - **F5 磁带**：选一份档案和一稿「从磁带恢复」，和第九稿对照
- **告示板**：点卡片打开那份档案；点墙上的钟换一个区的时间
- **沙发和放映机**（`2`）：坐下来正对墙上的投影幕，旁边推车上是一台 80 格转盘式幻灯机（RO-DS Model 80，1979 年）。左栏或点放映机开灯：屋里的大灯自动调暗，光束里飘着灰尘，片子真的投在幕布上，先虚后实。`←` `→` 换片（托盘转一格、片子掉进片门、对焦），`空格` 开灯 / 下一张，「自动」每 7 秒换一张。点幕布也是下一张。离开沙发角落，灯会亮回来。
  - **片盒**：每盘托盘装在自己的纸盒里，盒子侧立在茶几边的木箱里，书脊朝上。点木箱里的盒子（或左栏「木箱里的片盒」）会把它拿出来、打开盒盖举到眼前，左栏问「是这盒吗？」：放上放映机，或者放回去（`Enter` 放上，`Esc` 放回）。放上去时，镜头跟到推车边：放映机上原来那盘先转回空格、取下、装回自己的盒子、送回木箱；新盒子搁在推车下层，托盘从盒里取出装到机器上。「把托盘取下来」只取不换；没有托盘时开灯，幕布上只有灯泡的一块白光。尺寸照实物：托盘直径约 245 mm，盒子 270 × 270 × 78 mm，片框 50 mm。
  - 片子和片盒全部自动生成，作者不用做：T-00 是全岛一盘（片头 + 大镇和有档案的区的区图 + 片尾），之后每个有档案的区一盘（区图，再是这一区每份档案的封面卡，档案有照片的话后面跟一张照片，最后片尾）；没写 `district` 的档案单独一盘「未分区」。每盘最多 80 张。盒子侧面的色条是盘里最高密级的颜色。
- **磁带机**（`4`）：餐边柜上的双卡座，旁边一个木制磁带架，每盘磁带躺在自己的格子里，书脊朝外（磁带多了磁带架会自己加列）。点架上的磁带（或左栏）会把它抽出来拿到眼前，左栏问「是这盘吗？」：放进 A 仓、放进 B 仓，或者放回去（`Enter` 放进空着的那个仓，`Esc` 放回去）。放进去就开始放：卷轴转、VU 表针跳、计数器走字。A、B 两仓各有一排键（放 / 倒带 / 退带），同一时间只放一盘，按另一仓的放音键，这一仓会停。退带时磁带从仓门弹出来，自己回到架上原来的格子。`空格` 或点卡座本身是当前这一仓的放 / 停，点仓里的磁带也一样。换房间角落音乐不停。所有声音都走一条「磁带」通道：一点抖晃、高频削掉、轻微饱和，底下垫着嘶声和 50 Hz 交流声。
  - **音乐带** MX-01–03：《雨季》《末班车》《年份字段》，全是 WebAudio 现场合成（`src/app/office/music.ts`），没有采样
  - **Heuss 口述** DS-14：浏览器自带的语音念，句子之间有口述机暂停键的咔哒声。文字在 `src/data/tapes.json`，随便改
  - **档案朗读**：每份档案自动一盘，读编号、标题、区、日期和摘要（只读第九稿）。涂黑的地方念成一声 1 kHz 的「哔」。中文模式下读中文版

内容全部从现有档案自动生成（`src/lib/machine.ts`），屏幕上的回应用 SYSTEM 的口吻。旧网址 `/machine/` 会自动转到这里。

#### 给磁带机放自己的录音（可选）

和照片一样，音频文件放进 `public/tapes/`（mp3 / ogg / m4a / wav 都行），然后二选一：

- **某份档案的录音**：在档案开头加一行 `audio: "tapes/e-0004.mp3"`，这份档案的磁带就放这段录音，不再用合成语音念。
- **单独一盘带子**：在 `src/data/tapes.json` 的 `tapes` 里加一项：

  ```json
  { "id": "rain-1999", "kind": "file", "label": "TP-01", "title": { "en": "Rain, 1999", "zh": "雨，一九九九" }, "src": "tapes/rain.mp3" }
  ```

  `label` 是磁带侧面的编号，`title` 写在磁带标签上。给音乐带加 `src` 也行，就会放录音而不是合成曲。

录音同样会过「磁带」通道，所以听起来像是从这台卡座里放出来的。

### 档案室的开盘录音机

阅档桌右边、靠窗的角落里，一只柚木矮柜上放着一台 **Studer A807 MK II** 开盘录音机（瑞士 Studer 1992–2002 年产的广播级双轨机），照实物尺寸做：宽 465、高 500、深 265 毫米，10½ 寸 NAB 金属盘探出机身两侧。面板照一张实物照片排：上半是走带部分（两只盘、导带轮、张力臂旋钮、印 STUDER 的磁头罩、右边的剪接槽），下半是表桥（计时窗、RESET TIMER / ZERO LOC、TIMER · LOC 1 · LOC 2 · LOC START · LIFTER、浅灰色的 ◁ ▷ PLAY STOP REC，两块橙色背光 VU 表，每声道 READY / SAFE、INP / SYNC / REP 指示灯和录放电平旋钮，右边耳机孔、监听选择和速度灯）。机器底下垫着黑色矮木座；矮柜开格里竖着一排盘带盒，书脊朝外。

- 点机器（或左栏「录音机」，键盘 `6`）走过去。点架上的盒子或纸条上的名字就上盘：带盒整盒从开格里抽出来，拿起转成正面朝你，盒盖沿书脊翻开，盘从盒里拿出来装到左边轴上，再合盖、空盒放回开格；右边那只空的收带盘一直留在机器上（真机也是这样）。机上原来那盘如果放到一半，先自动倒回开头；下盘时空盒抽出来翻开，盘放回盒里，合盖放回开格。
- PLAY / STOP / ◁ 倒带 / ▷ 快进 / ZERO LOC 倒回开头 / LOC START 回到上次按 PLAY 的地方，机器上的键能按，纸条上也有一排大键给手机用。REC 按不下去：两个声道都在 SAFE。
- 放的时候两只盘照真实带速（7½ 英寸每秒）转，左盘越放越小、右盘越放越大，转速跟着各自的半径变；VU 表针跟着真实音量摆，计时窗走秒，PLAY 上的绿灯亮。坐下来读档时音乐接着放，离开档案室会停。下雨天放歌时，窗外的雨声慢慢压低、只剩细细的雨点，停了又慢慢回来。
- 盘带就是 `src/data/tapes.json` 里所有的音乐带（现在是 MX-01–03），作者的录音加一项并写 `"reel": true` 就会出现在这里（文件照样放 `public/tapes/`）。代码在 `src/app/archive/studer.ts`（模型）、`reels.ts`（盘带清单），走带和办公室卡座共用 `src/app/office/deck.ts`，音色分两套：卡座是磁带味（摇晃明显、高音切到 7 kHz、底噪大），录音机是开盘机的温润（7½ 英寸每秒走带稳、高音保留但柔一点、放音磁头在 85 Hz 左右把低音托厚一点、磁带轻微饱和、底噪小，再加一点房间里的回声）。
- **自带盘带** HM-01–03：开格最右边有三只空白盒，访客可以放自己的歌。点空白盒（或纸条上的「放自己的歌」），从自己的设备选一个音频文件，书脊上自动印「HM-01 · 歌名」（有 ID3 标题用标题，没有就用文件名，《》「」里的字优先、【】里的去掉），纸条上能改名、能清空。文件只存在访客自己的浏览器里（IndexedDB），不上传、别人听不到，下次来还在架上。商用歌曲不放进仓库和网站；代码在 `src/app/archive/homeReels.ts`。
