# THE NINTH DRAFT · 第九稿

一座冷战风格的解密档案馆。网站默认英文，右上角 `EN / 中` 可以切换中文（按 `L` 也行）；本说明为中文。

## 世界观：霏微

档案馆属于 **Gerimis / 霏微**（马来语「细雨」）：一座海峡里的小岛，时间永远停在 1999 年。岛上有一个 **记录署 / Records Office**，负责把发生过的事整理成最终版本（第九稿）。但被划掉的旧稿不会消失，它们会悄悄漏回现实，叫做 **回流 / Backflow**：填掉的海重新露出来，拆掉的老村一夜亮灯，路牌挂回旧名，被「修订出去」的人又走回街上。

> 本岛一切如常。如有不同，是上一稿。

地理参照新加坡，人物和机构全部虚构。一个核心区加六个居民区：

| 区 | `district` | 参照 |
| --- | --- | --- |
| 中枢 Axis | `axis` | 核心区（牛车水、直落亚逸、莱佛士坊、滨海湾），记录署总部 |
| 红桥 Pons Ruber | `pons-ruber` | 宏茂桥 |
| 大泽 Palus Magna | `palus-magna` | 大巴窑 |
| 红丘 Collis Ruber | `collis-ruber` | 红山 |
| 后港 Portus Posterior | `portus-posterior` | 后港 |
| 林地 Silva | `silva` | 兀兰 |
| 实龙岗 Serrangon | `serrangon` | 实龙岗 |

档案由作者和朋友们一起写，中文或英文都可以；写作须知、红线和交稿格式见项目文件里的「入馆须知」。一个不明说的约定：回流事件的日期尽量落在某月 9 号。

访问者走进一间档案室：一排排钢制抽屉里插满马尼拉纸档案夹，用长焦镜头拍摄。选中的档案会从抽屉里升起，打开后飞到镜头前翻开封面，露出夹着回形针的照片页和借阅登记表，右侧同时展开打字机风格的档案正文。太空元素只作为风格出现：轨道线、星图坐标、档案馆徽章上的卫星，不限定内容题材。

视觉与交互参考了《明日方舟》「莱茵生命：访问」的档案终端（[RhineLabUI](https://github.com/LBEILC/RhineLabUI) / [Rhine-Music-Demo](https://github.com/RonaldDeng/Rhine-Music-Demo)）和 [OHM TAPE](https://github.com/zcy83821448/cassette) 的「没有硬切」原则。代码、模型、贴图、音效全部为本项目原创，场景完全程序化生成，没有使用外部模型或图片。

## 功能

- **3D 档案室**（Three.js）：抽屉、档案夹、回形针、印章、打字机文字全部用代码生成
- **浏览**：`↑ ↓` 翻档案（前面的档案会向前倾倒），`← →` 换抽屉，滚轮或拖动也可以翻，点击档案选中，再点一次打开
- **档案详情**：档案飞到镜头前翻开，随后正文摊成一张纸，居中一页读完：摘要、正文、附件依次往下排，不分栏目；页脚的时钟和左侧编号在阅读时收起
- **涂黑文字**：正文里 `||这样写||` 会显示为黑条，鼠标悬停或点按后显示
- **关联档案**：`related` 字段自动生成双向「另见」，排在纸的最后一行；正文里写到的档案编号（如 E-0001）会自动变成引用记号，点开先出一张小便条（编号、标题、摘要），再决定要不要调出来。还没到日期的档案，编号只显示「还没归档」
- **原地读**：档案只在档案室里读。资料室、办公室和其他页面上点到档案，原地出一张调阅单：编号、密级、摘由、存放位置（如「档案室 · 第 02 抽屉 · 第 01 夹」），想看全文再点「去档案室调阅」，看完按 Esc 回到原来的地方
- **线索墙**（第二个房间，`/wall/`）：所有档案以卡片钉在软木板上，红线直接来自 `related` 字段，不用多写任何东西。按 `W` 或点档案室页头的 Links 进入（只在档案室里显示，之后并进办公室），档案纸面最后一行也可以「Show on the link wall」。鼠标停在卡片上只显示它的联系；卡片可以拖动，红线会下垂摆动；点击卡片回到档案室打开它。滚轮缩放，拖动空白处平移，`← →` 轮流聚焦，Reset wall 恢复原来的排布。拖过的位置只保存在你自己的浏览器里
- **战术层**（线索墙上）：软木板上印着地图网格（列 A、B、C…，行 01、02…），每张卡片左下角有目标框、威胁等级（按密级 0–4 个菱形）和联系数 `LNK`。一道扫描带定时从左扫到右，扫过的卡片会亮一下；聚焦的卡片四角出现锁定框。鼠标在板上移动时，页脚的天文坐标换成板面坐标和网格编号，左侧说明也会标出卡片所在格。这些都从现有字段自动生成。系统开启「减少动态效果」时不扫描
- **调取条**：每次打开档案，详情栏顶部先出现一条 ARCHIVIST 的调取进度（抽屉号、档案位置、分段进度条），下面附一句提示或吐槽。详情栏的内容跟着进度条自上而下显现，一条细扫描线压在显现的位置上：进度到多少，内容就显示多少。加载完后调取条自动收起。档案里有 Heuss 批注时，提示会告诉你批注在第几稿
- **从别的房间打开**：调阅单上点「去档案室调阅」会记住你从哪来，读完按 Esc 或左上角的返回，转场回到原来的房间
- **导航**：页头只有三间房加地图（档案室、资料室、办公室、地图），入馆登记和入馆须知在右上角。日报从资料室报刊架上的「今天的报纸」进，年历从办公室告示板旁的挂历进；旧网址 `/daily/`、`/calendar/` 照样能打开
- **旧稿**：有修订标记的档案，旧稿压在定稿下面，纸的右边露出几张旧稿的边（手机上排在纸的上方）。只放档案 `drafts` 里写到、而且日期已经到了的那几稿；没写 `drafts` 时按修订标记自动挑出有改动的稿。抽出一张，纸变成那一稿的样子，盖上 SUPERSEDED 章：这一稿新加的句子用红笔圈出，后来被改掉的用红色虚线框出，自动滚到改动处。键盘 `[` `]` 也能翻
- **Heuss 批注怎么找**：哪张旧稿的页边有 Heuss 的批注，它的边上就有一个蓝点；调取条的提示也会说批注在第几稿
- **SYSTEM 提示**：除了 ARCHIVIST，档案馆还有一个冷冰冰的机器声音 SYSTEM。翻阅档案、揭开涂黑、翻回早期稿、进入线索墙时，它偶尔会在屏幕顶部弹出一句提示（如 "Access logged."），开着声音时用合成女声读出来。密级越高越容易出现，两次之间至少隔 25 秒。台词在 `src/data/system.json`
- **开机音效**：第一次进入时点 Enter，会听到继电器咔哒、电源嗡鸣升起和两声提示音，SYSTEM 报一句 "Terminal online"。同一次浏览里再刷新页面，第一次点击时会播放一段短的开机声
- **附件**：纸面最下面是夹在档案上的纸片，点一下可以拿起来看。每份档案都自动带一张传阅单（Routing slip），内容来自 `drafts` 和 `related`；想多夹东西就写可选的 `attachments` 字段（写法见下文）
- **绕线档案袋**：密级为 TOP SECRET 的档案在抽屉里不是马尼拉档案夹，而是牛皮纸绕线档案袋：封舌上一颗纤维扣，袋身一颗，棉线 8 字形绕在两颗扣上。打开时线一圈圈松开（扣跟着转，线头垂下），封舌掀起，档案从袋口抽出来平放在袋上；合上时整段倒放，线重新绕回去。按现有的 `stamp` 自动判断，不用另外标记
- **套色网点照片**：档案的 `image` 照片会在浏览器里自动转成网点，用黑、红两色套印，红版故意错开一点。3D 档案夹内页、详情栏 Overview 和线索墙卡片上都用这张网点照片。没有照片的人员档案会显示一张代码生成的网点剪影（每个编号的剪影都不一样），说明文字写 "No photograph on file · Composite"；有照片时显示 `imageCaption`
- **Programs 章节页**：每次访问第一次打开 Programs 抽屉时，会先闪过一张构成主义风格的章节页（斜向红块、黑色楔形、超宽小写标题、徽章、档案数量和年份范围），约两秒后自动消失，点击或按任意键可以跳过。NASA 蓝只在这里出现
- **光圈转场**：两个房间之间用相机光圈切换，六片叶片收拢再张开；系统开启「减少动态效果」时改为淡入淡出
- **检索**：按 `/` 打开全文检索，可以搜索标题、编号、字段和正文
- **昼 / 夜**：白天是灰白档案室；夜晚只有一盏台灯照着当前档案，切换时颜色平滑过渡
- **声音**：环境底噪加低频嗡鸣，纸张、抽屉、盖章、打字等音效；切换抽屉时有调频杂音，Programs 抽屉里能听到 Sputnik 的「哔—哔—」；每隔一两分钟，远处的数字电台会放一段旋律，再报一组数字。全部实时合成，可以随时关闭
- **中英切换**：右上角 `EN / 中` 或按 `L`。界面、ARCHIVIST、SYSTEM 全部双语，中文模式下 SYSTEM 用中文女声朗读；3D 档案夹封面和内页、线索墙卡片也会重新打字。印章、档案编号、口令保持英文。选择会被记住，默认英文。切换时淡出淡入，没有硬切
- **基线测试**（`/baseline/`）：致敬《银翼杀手 2049》开头的复述测试，台词全部原创。一间白色的平面隔间（照原片：只有声音的审讯、旁边一台虹膜扫描仪、底部一条脉搏线），不用 3D。SYSTEM 念一句、你点选或按 1/2/3 原样复述，共九句、每句十秒；答过的词留在隔间里，答偏的被红线划掉。偏差越大，整页越波动（SVG 位移滤镜、色散），瞳孔放大、脉搏变红；判成「偏差」时接 1900 倒回闪回。**隐藏触发**：九句没有一句照原样复述，会在闪回后黑屏，被请到 `/exit/`——纯黑一页，只有一句话（「本稿无此人。」/ "No such person in this draft."），句末的句号是回档案馆的链接。结果分稳定 / 偏移 / 偏差三档，只存在本机，显示在「我的档案」。减少动态效果时不波动不抖动
- **入馆登记**（`/register/`，右上角 Register）：访客在三号窗口办理（办事员逐步提问：代号、点地图选住处、三道例行问题、可选的一句话、核对；右侧证件卡实时成形，归档时有办理动画），拿到 `V-` 开头的档案编号、临时居民章和四个英文单词的恢复口令。全部只存在访客自己的浏览器里，不收集真实信息；换设备时输入代号和口令即可找回（那一句话除外）。没登记的访客，ARCHIVIST 每次浏览会提醒一次；登记后它会叫出你的代号
- **我的档案**（`/me/`）：和人员档案同样的排版，网点剪影由编号生成。有一个「小秘密」，只有自己看得到，也有九稿：定稿是署方口径、关键句涂黑，越往前说得越直白，第 2、3 稿有 Heuss 的批注。秘密由模板拼成（六种类型 × 住处 × 答案 × 那一句话），还会自动点名一份真实档案（优先同区的），作者不用为它写任何东西。模板在 `src/app/visitor/secret.ts`。第一次打开时，档案装在一个封口的牛皮纸绕线档案袋里送来：绕着下面那颗扣转圈，每转一圈解开一圈线（也可以点「帮我绕开」），线头掉下、封舌掀起、档案从袋口抽出来。打开过一次就记在本机，之后直接显示；页尾「重新封上」可以再看一遍
- **霏微地图**（`/map/`）：代码画的平面地图，七个区，档案按 `district` 字段自动钉上去，访客住的区会亮。没写 `district` 的档案不上图
- **入馆须知**（`/guide/`）：告诉第一次来的人这里是哪里、能做什么
- **小巧思**（不上锁，到处点点就能碰到，代码在 `src/app/ui/quirks.ts`）：
  - 页脚的年份 `Dec 1999` 可以点：它想翻到 2000，跳成 1900，又退回 1999，SYSTEM 说一句 "Year rollover denied."。三秒内连点九下，整页会在暴雨里倒回泛黄的 1900（页面上的年份一路倒数，页脚也变成 1900），随后被盖上 REVISED 章修订回 1999；系统开启「减少动态效果」时只淡入淡出，不下雨不抖动
  - 档案照片按住不放会显出底片（反色），松手恢复
  - 档案标题右下角的 Stamp 按钮可以给这份档案盖你自己的章（VERIFIED → TO BE CORRECTED → REJECTED → 撤掉），只存在你自己的浏览器里
  - 左下角 ARCHIVIST 那行字可以戳，连戳五下它会生气
  - 鼠标点哪里都会留下一个慢慢洇开的墨点（触屏和「减少动态效果」时不显示）
  - 切走标签页时标题变成「Gerimis · Backflow in progress…」，离开超过 8 秒再回来，ARCHIVIST 会说一句
  - 从档案里复制文字，会自动带上一行「— Records Office, Gerimis · Revised · Draft 09」
  - 不存在的网址会打开 404「该页已被修订出去」；打开开发者工具的控制台还有一句留言
- **每份档案都有独立网址**（`/records/p-0001/`），可以直接分享
- 适配手机竖屏；系统开启「减少动态效果」时自动降级

## 添加 / 修改档案

每份档案是 `src/content/records/` 下的一个 Markdown 文件，子文件夹只是为了方便整理：

```markdown
---
file: "P-0005"                 # 档案编号，必须唯一
category: personnel            # personnel 人员 / events 事件 / programs 计划
title: "Full Name"
subtitle: "Role or alias"
stamp: "SECRET"                # TOP SECRET / SECRET / CONFIDENTIAL / RESTRICTED / DECLASSIFIED
status: "On duty"
date: "1971 –"
place: "Palus Magna"           # 读者看到的地名
district: palus-magna          # 可选，地区代号（见上面「世界观」的表），地图和访客秘密会用到
image: "records/p-0005.jpg"    # 可选，图片放在 public/records/ 下
fields:
  - label: "Role"
    value: "Ferry pilot"
summary: "Overview 栏的摘要，可以用 ||涂黑||。"
related: ["P-0001", "E-0002"]  # 关联档案的编号
tags: ["ferry"]
order: 5                       # 在同一类别里的排序
---

Record 栏的正文，标准 Markdown，同样支持 ||涂黑||。
```

保存后，开发模式下页面会自动刷新；推送到 `main` 后会自动部署。

### 修订痕迹（第九稿）

在 `summary`、`fields` 的值或正文里加修订标记，档案下面就会压上旧稿（纸面右边露出的那几张）。稿号 1–8 是旧稿，第 9 稿就是你写的定稿（界面上只叫「定稿」）；没有任何标记的档案没有旧稿。抽出旧稿时，3D 档案夹封面和内页上的印章也会换成那一稿的密级。`drafts` 里写了日期的稿，日期到了才会出现。

| 写法 | 效果 |
| --- | --- |
| `[[+5: 文字]]` | 第 5 稿新加入（那一稿用红笔圈出），之前的稿里不存在 |
| `[[-6: 文字]]` | 第 6 稿被红线划掉，之后消失 |
| `[[#3-7: 文字]]` | 第 3–7 稿被涂黑；只写一个数字（如 `[[#3: …]]`）表示从第 3 稿起一直涂黑 |
| `[[note 4-6: 文字]]` | 第 4–6 稿出现手写批注，自动署名 **— Heuss**；只写一个数字表示仅那一稿 |
| `\|\|文字\|\|` | 定稿中的涂黑，读者悬停或点按可以揭开 |

每一稿的标签、日期、经手人和印章可以在 frontmatter 里写（可选，不写就用默认值）：

```yaml
drafts:
  - n: 1
    label: "Field notes"
    date: "1959-11-04"
    by: "A. Reiss"
    stamp: "DRAFT"        # DRAFT / TOP SECRET / SECRET / CONFIDENTIAL / RESTRICTED / DECLASSIFIED
  - n: 5
    label: "Amended"
    by: "Heuss"
    stamp: "TOP SECRET"
```

滑到哪一稿，界面颜色就跟着那一稿的密级变化。

### 附件（可选）

每份档案都会自动生成一张传阅单，不用写任何东西。想在档案上多夹几样东西，就在 frontmatter 里加 `attachments`：

```yaml
attachments:
  - "直接写一句话，就是一张 Heuss 署名的便条。"
  - kind: telegram          # 电报：自动大写，句号变成 STOP
    title: "Halden to Oslo"  # 发报路线
    date: "1959-11-03"
    text: "Carrier steady on 4.625. Request instructions."
  - kind: ticket            # 票根：title 是票名，自动生成编号
    title: "Coastal Steamer"
    text: "Tromsø to Hammerfest, deck passage"
    date: "1958-02-14"
  - kind: clipping          # 剪报：title 是标题
    title: "Mapmaker returns from the ice"
    text: "正文里也可以用 ||涂黑||。"
  - kind: negative          # 底片条：用档案照片（没有照片就用剪影）自动生成三格负片
    text: "说明文字"
    draft: 4                # 可选：从第 4 稿起才夹进档案，抽出更早的旧稿时会消失
  - kind: note
    text: "便条也可以换署名。"
    by: "Morozov"
```

`kind` 可选 `note`（便条，默认）、`telegram`、`ticket`、`clipping`、`negative`。所有文字照例写英文。

### 密级颜色

| 密级 | 颜色 |
| --- | --- |
| TOP SECRET | 朱红 |
| SECRET | 琥珀 |
| CONFIDENTIAL | 钴蓝 |
| RESTRICTED | 橄榄绿 |
| DECLASSIFIED | 墨黑（夜间为纸白） |

档案夹标签、印章墨色、界面强调线、页面背景的大编号、夜间台灯色温都会跟着当前档案的密级变化。

### ARCHIVIST（档案馆管理员）

页面左下角的那行话来自 `src/data/archivist.json`。每类事件（欢迎、开抽屉、打开某个密级的档案、翻回早期稿、揭开涂黑、检索无结果、发呆太久、进出线索墙、调取档案时的提示 `retrieve`、线索墙扫描 `sweep` 等）都是一组台词，随机挑一句说。`{title}`、`{file}`、`{draft}` 会自动替换成当前的档案标题、编号和稿号。想加多少句都行。

## 中文版

### 给档案加中文版（可选）

在英文档案旁边放一个同名的 `*.zh.md`，例如 `personnel/p-0002.md` 旁边放 `personnel/p-0002.zh.md`。没有中文版的档案在中文模式下照常显示英文原文，不会出错。

朋友交来的稿子可以是中文也可以是英文。网站仍以 `.md` 为主文件、默认显示英文，所以中文写成的稿子由我们补一份英文 `.md`，中文原文放进 `.zh.md`。

```markdown
---
file: "P-0002"            # 必填，对应英文档案的编号
title: "Heuss"
subtitle: "记录署数据组技术员"
summary: "……"
fields:
  - label: "职务"
    value: "数据组技术员，年份字段整改"
---

正文（修订标记、涂黑、批注的写法和英文完全一样）
```

- 除 `file` 外全部可选：`title`、`subtitle`、`status`、`date`、`place`、`imageCaption`、`fields`、`summary`、`tags`、`drafts`、`attachments`。没写的字段沿用英文。
- `drafts` 只需写 `n` 和要翻译的 `label` / `by`；`attachments` 按顺序对应英文的附件，可以只写文字（字符串）或 `{title, text, date, by}`。
- 密级、照片、`related`、印章、编号都跟英文档案共用，不用重复写。
- 检索同时索引中英两种文字，用哪种语言都能搜到。

### 翻译的语气

中文要像中文，不要翻译腔。可以比英文更幽默、诙谐，甚至带点讽刺，但不能偏离原意。ARCHIVIST 可以更损一点；SYSTEM 照样冷淡、简短、从不开玩笑。

### 台词与界面文字

| 文件 | 内容 |
| --- | --- |
| `src/data/ui.zh.json` | 界面文字，以英文原文为键，`{n}` 之类的变量照写 |
| `src/data/archivist.zh.json` | ARCHIVIST 中文台词，分组和英文相同 |
| `src/data/system.zh.json` | SYSTEM 中文台词 |

字典里没有的界面文字会显示英文，所以漏翻不会坏，只会露馅。

### 字体（「机械铭牌」）

| 用途 | 字体 |
| --- | --- |
| 大标题 | 站酷酷黑 |
| 正文 | 寒蝉活宋体·復 |
| 标签、小字 | 寒蝉德黑·窄（粗体作标题后备） |
| SYSTEM 提示 | 寒蝉点阵体 |
| Heuss 批注 | 汇文仿宋 |

母本放在 `fonts-src/zh/`（已裁到 GB2312 范围）。`npm run build` 时 `integrations/zh-fonts.mjs` 会数一遍输出里实际用到的汉字，按用得多少排序后**切块**：最常用的约 600 字一块，往后每 200 字一块，每种字体都切成同样的几块，放到 `dist/fonts/zh/`，规则写在 `faces.css`。每块用 `unicode-range` 声明，浏览器只下载当前页面真正用到的那几块：只看英文的访客几乎不下载中文字体，书里的生僻字也只在翻到那一页时才下载。块的文件名带内容哈希，换了内容不会读到旧缓存。加了新的中文档案或书不用做任何事，下次构建会自动重新切；只有用到 GB2312 以外的生僻字时才需要换母本。画在 3D 场景里（canvas）的中文不会自己触发下载，场景代码画字前要先调 `canvasFontsReady(文字)`。

许可：寒蝉系列为 SIL OFL；站酷酷黑免费商用；汇文仿宋免费商用、不得单独售卖字体。

### 霏微日报

`/daily/` 是岛上的报纸，**不用另外写**，构建时从档案自动排版：

- 有日期的事件、计划 → 当天的头版
- `kind: clipping` 的附件 → 当天报纸上的一篇文章（标题写成 `Gerimis Daily · page 6` 会标出版面）
- 有日期的修订稿 → 「更正」栏（报纸上的更正，就是档案的修订）
- 其他带日期的附件 → 「档案摘录」
- 天气、分类广告、潮汐按日期从固定的题库里挑，同一天永远印同样的内容

报纸只印官方版本：被划掉的句子、Heuss 的批注都不会上报，涂黑的地方也揭不开。12 月 31 日那一期永远会出。

### 资料室（第三个房间）

`/library/` 是记录署的阅览室，做成一个**剖面模型**放在纸面上：揭掉两面墙和屋顶，镜头和档案室一样是斜俯视的长焦。白天日光从后墙的拱窗斜射进来，在地板上投出窗格光斑，光柱里有浮尘；夜里窗外的组屋亮灯，阅览桌上方的乳白玻璃球吊灯亮起。黄铜、清漆会反射环境光。

房间里有四个角落，`0–4` 或左栏切换，点模型里的东西也能过去：

- **报刊架**：《霏微日报》一个月一根报杆。1999 年每天都有一期，有档案事件的日子是新闻，其余是平常日子
- **书墙**：左墙通高书架。登记过的书按书号散在整面墙上，各区区志在够不着的高层（区志是公开出版物，只写本区大事记，不列档案编号）。在左栏点书（或把鼠标移上去），镜头会沿着书墙走到它面前；取高层的书时，移动书梯会先沿轨道滚过去
- **目录卡片柜**：一份档案一张卡。拉开抽屉，右边列出卡片，点卡片出一张调阅单（摘由和存放位置），要看全文再自己去档案室调；空抽屉留给还没进来的档案
- **借还台**：柜台取阅的入馆须知；你的借书记录，可以在借书卡上盖今天的日期

取书按人的节奏来：手指先把书顶勾出来，书被慢慢抽出，左右两本书歪向空位；拿到眼前，先看书脊，再转过来看封面，确认是要的那一本；高层的书随人从梯子上下来；然后拿着走到阅览桌（按距离算，约每秒 1.5 米，手里的书随步子轻轻起伏），放平、落到桌上，最后翻开封面，右边出现阅读栏。镜头一路跟着书，夜里那盏暖光也跟着书走。整段 7–10 秒，进行中点一下画面会加速；放回去是倒放，快一些。

**书的厚度跟着页数走**：内容少的是骑马钉小册子，档案多了下次构建自动变厚。书全部从现有内容自动装订（`src/lib/library.ts`），场景在 `src/app/library/`。

**画质**：默认全开（每本书都投影、4096 阴影贴图、吊灯白天也亮、光柱和浮尘）。页面开头会测帧率，只有设备跟不上时才一级一级往下降（先降分辨率，再关书的投影，最后关吊灯实时光和光柱），不会再升回去，免得画面闪。网址后面加 `?perf` 显示帧率、当前档位和显卡型号；加 `?full` 锁定全画质，不自动降级。

### 资料室的书（公版书）

书放在 `src/content/books/`，**一本书一个 `.md` 文件**，照原文的语言放（中文书就是中文，英文书就是英文），只放版权已过期的书：

```markdown
---
title: 朝花夕拾
titleAlt: Dawn Blossoms Plucked at Dusk   # 另一种语言的书名，书脊和卡片用
author: 鲁迅
authorAlt: Lu Xun
year: '1928'
lang: zh            # zh 或 en
source: 维基文库    # 底本从哪来，印在扉页上
order: 10           # 越小越靠前（可选）
---

## 小引

正文……

## 狗·猫·鼠

正文……
```

- `## ` 是章节标题，自动生成目录，点目录直接翻到那一章；太长的章自动切成几页（中文约 900 字一页，英文约 2200 字）
- 书的厚度跟页数走，散放在书墙中间几层；封面印「公版 · 年份」，不印记录署
- 正文另存成 `library/books/<文件名>.json`，取书时才下载，所以书再多也不拖慢资料室；生僻字所在的字体块也是翻到那页才下载

### 办公室

`/office/` 是记录署地下一层数据组的办公室，Heuss 上班的地方，也是第四间 3D 房间。画面语言和另外三间一样：纸上的剖面模型、斜俯视长焦、左栏 + 页脚。窗户开在人行道高度，白天百叶窗把阳光切成一条条落在地上，晚上外面是路灯和雨，屋里只剩台灯、落地灯和屏幕的琥珀光。挂钟按真实时间走，挂历停在 1999 年的今天（每个 9 号有个小点），告示板上钉着最新的五起回流事件。

`0–4` 或左栏切换角落：整间办公室、办公桌和电脑、沙发、告示板、磁带机。点模型里的东西也会推近，`Esc` 拉回全景，方向键轮换。

- **办公桌**：一台 CRT 台式机，屏幕是真正的网页，贴在 3D 显示器上，可以直接点、直接打字。`F1–F5` 切换程序：
  - **F1 终端**：`HELP`、`LS`、`OPEN E-0004`、`DIFF E-0004 3`、`LOG`、`YEAR`、`ROLLOVER`、`CLOCK`、`SYNC`、`WHO`、`CLEAR`、`LOGOUT`（屏幕熄灭，镜头退回全景）
  - **F2 日志**：全岛所有带日期的修订记录，点一行调出档案
  - **F3 年份**：`YEAR: 99`。「跨年测试」会跳到 00、被读成 1900、整屏乱码，然后自动回滚（接 R-0001）
  - **F4 时钟**：七个区的钟，林地快一小时、后港慢一小时，同步后又滑回去（接 R-0003）
  - **F5 磁带**：选一份档案和一稿「从磁带恢复」，和第九稿对照
- **告示板**：点卡片打开那份档案；点墙上的钟换一个区的时间
- **沙发和放映机**（`2`）：坐下来正对墙上的投影幕，旁边推车上是一台 80 格转盘式幻灯机（RO-DS Model 80，1979 年）。左栏或点放映机开灯：屋里的大灯自动调暗，光束里飘着灰尘，片子真的投在幕布上，先虚后实。`←` `→` 换片（托盘转一格、片子掉进片门、对焦），`空格` 开灯 / 下一张，「自动」每 7 秒换一张。点幕布也是下一张。离开沙发角落，灯会亮回来。
  - **片盒**：每盘托盘装在自己的纸盒里，盒子侧立在茶几边的木箱里，书脊朝上。点木箱里的盒子（或左栏「木箱里的片盒」）会把它拿出来、打开盒盖举到眼前，左栏问「是这盒吗？」：放上放映机，或者放回去（`Enter` 放上，`Esc` 放回）。放上去时，镜头跟到推车边：放映机上原来那盘先转回空格、取下、装回自己的盒子、送回木箱；新盒子搁在推车下层，托盘从盒里取出装到机器上。「把托盘取下来」只取不换；没有托盘时开灯，幕布上只有灯泡的一块白光。尺寸照实物：托盘直径约 245 mm，盒子 270 × 270 × 78 mm，片框 50 mm。
  - 片子和片盒全部自动生成，作者不用做：T-00 是全岛一盘（片头 + 各区区图 + 片尾），之后每个有档案的区一盘（区图，再是这一区每份档案的封面卡，档案有照片的话后面跟一张照片，最后片尾）；没写 `district` 的档案单独一盘「未分区」。每盘最多 80 张。盒子侧面的色条是盘里最高密级的颜色。
- **磁带机**（`4`）：餐边柜上的双卡座，旁边一个木制磁带架，每盘磁带躺在自己的格子里，书脊朝外（磁带多了磁带架会自己加列）。点架上的磁带（或左栏）会把它抽出来拿到眼前，左栏问「是这盘吗？」：放进 A 仓、放进 B 仓，或者放回去（`Enter` 放进空着的那个仓，`Esc` 放回去）。放进去就开始放：卷轴转、VU 表针跳、计数器走字。A、B 两仓各有一排键（放 / 倒带 / 退带），同一时间只放一盘，按另一仓的放音键，这一仓会停。退带时磁带从仓门弹出来，自己回到架上原来的格子。`空格` 或点卡座本身是当前这一仓的放 / 停，点仓里的磁带也一样。换房间角落音乐不停。所有声音都走一条「磁带」通道：一点抖晃、高频削掉、轻微饱和，底下垫着嘶声和 50 Hz 交流声。
  - **音乐带** MX-01–03：《雨季》《末班车》《年份字段》，全是 WebAudio 现场合成（`src/app/office/music.ts`），没有采样
  - **Heuss 口述** DS-14：浏览器自带的语音念，句子之间有口述机暂停键的咔哒声。文字在 `src/data/tapes.json`，随便改
  - **档案朗读**：每份档案自动一盘，读编号、标题、区、日期和摘要（只读第九稿）。涂黑的地方念成一声 1 kHz 的「哔」。中文模式下读中文版

内容全部从现有档案自动生成（`src/lib/machine.ts`），屏幕上的回应用 SYSTEM 的口吻。旧网址 `/machine/` 会自动转到这里。

#### 给磁带机放自己的录音（可选）

和照片一样，音频文件放进 `public/tapes/`（mp3 / ogg / m4a / wav 都行），然后二选一：

- **某份档案的录音**：在档案开头加一行 `audio: "tapes/e-0004.mp3"`，这份档案的磁带就放这段录音，不再用合成语音念。
- **单独一盘带子**：在 `src/data/tapes.json` 的 `tapes` 里加一项：

  ```json
  { "id": "rain-1999", "kind": "file", "label": "TP-01", "title": { "en": "Rain, 1999", "zh": "雨，一九九九" }, "src": "tapes/rain.mp3" }
  ```

  `label` 是磁带侧面的编号，`title` 写在磁带标签上。给音乐带加 `src` 也行，就会放录音而不是合成曲。

录音同样会过「磁带」通道，所以听起来像是从这台卡座里放出来的。
