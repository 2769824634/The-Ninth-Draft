## 第 1 次：地图上的设施

现在地图上只有组屋、街道、河、地铁，没有生活设施。居民登记要用到「楼下巴刹」「最近的巴士总站」，所以先补上。

- **巴刹和小贩中心**：组屋数据里本来就标了哪座楼下有巴刹 / 小贩中心，直接画出来，不用另找。
- **巴士总站、商场、邮局、综合诊疗所、民众联络所、图书馆、游泳池**：手工列一份 1999 年已经在的清单（`scripts/map/facilities_1999.py`），位置取 OpenStreetMap，名字用当地真名（不带政治人物名字，规矩同地名）。
- **学校**：只画位置，名字全部虚构（「宏茂桥第三小学」这一类）。
- **宗教场所**：只写外观，如「红顶庙」「绿圆顶清真寺」，不写名字和宗派。
- **年份规矩照旧**：1999 年以后才开的不画；1999 年以前没了的用红铅笔淡画。
- **画法**：照纸面测绘图，加图例里的小符号（巴刹一个方框加 M，巴士总站一个圆加 B 之类），不用手机地图那种彩色图标。点设施出小纸条（名字、开业年份、营业时间），地名索引里也能查到。
- **按邮编查**：楼下的巴刹、小贩中心跟着那一座组屋的邮编走，搜邮编就看到「楼下有巴刹」；巴士总站、商场、邮局等单独的设施各配一个邮编，搜邮编或名字都能找到；也能按「区 + 类别」搜，比如「宏茂桥 巴刹」。

## 第 2 次：两种登记分开，居民登记重做

**入馆登记（阅览证）** 变成很轻的一步：在档案馆门口的访客簿上签代号，「从哪来」照实写或不填，领一张阅览证。不分屋子。记住读到哪。

**居民登记（表格 RO-9）** 重做成一段办事流程：

1. 填表：代号、从哪来、勾一项「在本岛出生 / 通常居于本岛，自 ____ 年起 / 新抵岛人士」。原来的三个问题和「选填一句话」拿掉。
2. 新抵岛的先在渡轮码头填入境卡；另外两种不用。
3. 取号、叫号，到窗口。职员按你勾的那一项问话，三种各有一套台词（ARCHIVIST 那种老职员口气）。
4. 分住处：
   - 新抵岛和通常居住的：先选片再选区（现有的街道图），然后抽签，抽到具体的一座和单位（只抽 1999 年前建成、有住家的组屋），门牌照新加坡写法 `#07-123`。
   - 本岛出生的：不抽签，在地名索引里找小时候住的那一座，自己选楼层和门牌，记录署「按旧址补发」。
5. 拍照、过塑，身份证从机器里出来：正面姓名、出生日期、性别、出生地，日期下面一行代码（`G` / `R87` / `N`）；背面证号、签发日期、住址（`Blk 7 Lorong Lew Lian #03-311 · 霏微 531007`）。
6. 拿钥匙。「我的档案」改成「我家」：门牌、信箱、住址，在地图上钉出你那一座。

**旧数据不丢**：已经登记过的人照旧能打开，按「新抵岛」处理，下次来时在原来的区补抽一个单位。恢复口令要多记类别、年份和门牌，口令格式会变，旧口令照样能用。

**做的时候定下的（2026-10-08，可以改）**：

- 出生日期和性别照真实表格问（作者 2026-10-08 说「真实点的话确实需要」）：出生日期日-月-年三格，性别男 M / 女 F，证上照印。出生日期不在口令里，换设备找回时要再填一次，拿来核对。改版前的旧登记没有这两项，证上印 NOT DECLARED。
- 「从哪来」：通常居住的在表上问，新抵岛的在入境卡上问，本岛出生的不问（出生地印 GERIMIS）。
- 档案编号由代码和住址算出来，同一间屋子换设备找回还是同一个号。
- 恢复口令改成六个英文词（多记了类别、年份、楼层、门牌和性别），旧的四个词照样能用。
- 阅览证有效期写「Until 31.12.99」。
- 旧登记在「我家」页上补抽一次（按新抵岛），编号和口令随之换新。

## 第 3 次：岛上的人

- **每户人家**：按邮编和门牌算出来，谁看都一样：户主姓氏（华、巫、印、欧亚的常见姓，只用通用名字，不对应真人）、几口人、做什么工、住了几年。
- **十来个常露面的人**：我先写一版草稿给你看（楼下阿姨、面摊老板、邮差、巴士司机、报贩、杂货店头家、巴刹鱼贩、校工、咖啡店头手、德士司机、组屋管理处职员、记录署柜台阿姨），每人有住的区和一两句口头禅。朋友写档案时可以直接让他们出场。
- **出现在哪**：你那座楼的信箱墙（左邻右舍的名字）、你那层的门牌、楼下告示板的启事、日报读者来信的署名、设施小纸条里的摊主。
- **每个人碰到的不一样**：邻居由住处决定，小事由登记种子和本机记下的「去过哪、几次、几点」决定。这一步只搭好条件判断的骨架，第一批小事先放十来条。
- **前任住户的信**：信箱里两三封，按单位和登记类别生成（账单、明信片、过期日报）。

## 第 4 次：暗线和私人日记

- 居民证代码后面的 `P`、柜台那句「电脑自己加的，不用管」、某个条件下（比如第三次回家、某月 9 号）在「我家」页边出现的 Heuss 批注。
- 三种登记各自的旧稿痕迹（前任住户名字差一个字母 / 抵岛年份每稿不同 / 同一地址不同职业）。只有居民碰到。
- 私人日记：家里抽屉，只存本机，作者看不到；难过的内容在本机检测，旁边放求助便条（新加坡援人协会 1767，另附按国家查热线的网站）。
