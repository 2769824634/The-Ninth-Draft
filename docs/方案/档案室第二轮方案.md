YosH 提的三件事：看档案时左下角档案员的话没了；翻阅时几乎没有动画；灯光变化突兀、不合理。下面先说每件事的原因（看代码和上一轮截图查的），再说怎么改。

---

## 一、档案员的话为什么没了

**原因：上一轮我自己藏掉的。** 读档案时，纸底下的「上一份 / 下一份」和左下角那行字撞在一起，我图省事把那行字整个隐藏了（`dossier.css` 第 56 行）。结果档案员在你打开档案时说的那句话（按密级挑的台词）根本看不到。

**改法：** 读档案时，档案员的话挪到纸左边的空白处，就在「回到抽屉」下面，写在一张小便条上（和正文引用那种便条同一个样子），一句话一张，下一句来了旧的就淡掉。手机竖屏左边没空位，就在纸的上沿露一行，几秒后收起，点一下可以再看。这样不和「上一份 / 下一份」抢地方，也不用把它关掉。

## 二、翻阅为什么像没动画

**原因：** 现在打开档案，是一条「调取中」的进度条从上往下扫，纸面跟着显出来。这是早先浮空抽屉时代的「终端调取」做法，搬进房间以后就不对了：你明明是从抽屉里抽出一份纸，画面却像在电脑上加载。而且纸只是淡入、往上挪一点点；按「下一份」的时候，内容直接整页替换，什么也不发生。

**改法：把纸当纸。** 每个动作都对应房间里那份档案的实际动作，3D 和纸面接成一条线：

**和明日方舟那一层叠起来**（2026-10-08 YosH 提醒）：纸面是《重返未来》的物质层，界面骨架仍是明日方舟的系统层，两层同时在，不是只剩纸。打开一份档案约 1.2 秒：

- **系统先动**：一道密级色的细线划过；左边竖排书脊打出「ARCHIVE // E-0001 // CONFIDENTIAL」；背景超大编号从侧面滑入；顶上切角黑标签写「借阅登记 · 第 02 抽屉 · 第 01 夹」，后面一条进度条走完、盖一个「已登记」方块。进度条只是登记，不再遮住纸的内容。
- **实物接着动**：下面第 1 条，档案夹翻开、纸滑出来，落进刚才细线框出的位置。
- **收尾**：警示斜纹、密级色块最后出现；SYSTEM 一行照旧。
- 放回去倒过来：纸先收进夹子，线和标签再依次退场。
- 档案员便条也是两层：切角黑标签「■ ARCHIVIST」+ 下面的纸条。

1. **抽出来（就地翻看）**：3D 里档案从抽屉里升起来，镜头跟着推近一点；纸面就从那份档案在屏幕上的位置长出来，先是合着的档案夹（人员是马尼拉夹、事件是牛皮纸、TOP SECRET 是绕线袋，和抽屉里看到的一样），封面沿着折边翻开，里面那张纸滑出来摊平，带一点阴影落定。全程约 0.8 秒。「调取中」那条扫描线不再一行行遮住纸面，改成上面说的借阅登记条。
2. **放回去**：倒着来一遍，纸收进夹子，夹子合上，缩回抽屉里那个位置，3D 里档案落回去。
3. **上一份 / 下一份（在抽屉前）**：现在这份往下滑回抽屉，同时隔壁那份从它的位置升上来；3D 里镜头沿着抽屉挪一格。按方向走：下一份从右边来，上一份从左边来。
4. **上一份 / 下一份（在桌上）**：纸在桌面上横着推开，下一份从它在桌上的实际位置被拉过来。
5. **翻旧稿**：现在是整张转个角度；改成把上面那张从一角掀起来，露出下面那稿，放下时落回去。
6. **翻页**：长档案往下读时，纸底边加一道折痕阴影，读到一页的尽头像真纸一样有页脚和页码，不是一路滚到底。
7. **打字声、纸声**跟着这些动作走（翻开、滑出、落下各一个声音），现在只有开头一声。

系统开着「减少动态效果」时，全部换成 0.15 秒的淡入淡出。

## 三、灯光为什么突兀、不合理

查下来是四个原因：

1. **吊灯整排变色。** 现在打开一份 TOP SECRET，照着那排柜子的整排吊灯瞬间变成冷蓝；放回去又瞬间变回暖黄。颜色是一下子换的，没有过渡；而且没有道理，吊灯不会因为你拿了哪份档案而换灯泡。
2. **纸上的光是另画的，和房间里的灯没关系。** 纸面那团光固定从左上角来，强弱只有「台灯 / 月光 / 路灯 / 白天」四档，切档的时候纸的底色 0.5 秒变完、光晕 1.4 秒才变完，两个速度对不上，所以看着一顿一顿的。
3. **判断错地方。** 在抽屉前读，只看第二排吊灯开没开；第二排关了、别的灯全开着，纸上照样写「灯关着，这是路灯照的」。白天则完全不管灯。
4. **读的时候摸不到开关。** 开关在房间面板上，读档案时面板收起来了，所以「关灯借月光读」这件事你其实看不到它发生。

**改法：**

1. **吊灯永远不变色。** 密级的色温交给每个阅读位置自己的一盏「验档灯」：抽屉柜侧面有一盏夹在柜子上的摇臂灯，阅档桌上是那两盏黄铜台灯，再加一根日光灯管。岛上的理由：记录署规定，密级越高越要在日光灯下看，涂改和刮掉的字在冷光下才看得出来（和回流、旧稿是同一回事）。所以：
   - DECLASSIFIED、RESTRICTED：只开钨丝台灯，暖黄。
   - CONFIDENTIAL：台灯加灯管半亮，偏中性。
   - SECRET：灯管为主，偏冷。
   - TOP SECRET：只开灯管，最冷；灯管起辉时闪两三下，带一点嗡声。
   色温就是两盏真灯混出来的，不再给任何灯「刷颜色」。
2. **每盏灯照它自己的物理脾气亮和灭**：钨丝灯 0.3 秒左右慢慢亮起、熄灭时灯丝还红一下；日光灯管先闪再稳；昼夜交替按岛上时间慢慢过渡。所有灯一个规矩，不再有瞬间跳变。
3. **纸上的光从房间里算出来。** 每一帧按你读的那个位置实际照到的光（哪几盏灯开着、离多远、什么颜色，再加窗外的天光、月光、路灯、下不下雨）算出纸面的亮度和颜色，光斑的位置也跟着灯在画面里的方向走（灯在右边，光就从右边来）。不再分四档，所以不会一顿一顿。灯全关了照样能读，字的对比度有个下限。
4. **读的时候也能开关灯。** 纸左边空白处、档案员便条下面，放一排小开关：这里的验档灯、这一排吊灯、全屋。你在读的时候关掉，就能看着纸慢慢暗下去、换成月光或路灯。

---

## 要你定的两件事

1. **「验档灯」这个说法行不行？**（推荐：行）它把「色温随密级变」变成岛上的一条规矩，吊灯就可以不动了。不行的话，退一步是只换阅读位置那盏台灯的灯泡颜色，但要慢慢变。
2. **档案员的话放纸左边的便条上，行不行？**（推荐：行）另一个选择是放回左下角、把「上一份 / 下一份」挪到纸的右侧边缘。

## 做法和顺序

一个 PR，按「档案员的话 → 灯光 → 翻阅动画」的顺序做，因为灯光要先改成从房间算，翻开纸的时候光才对得上。做完照旧截图给你，你在线上试过再合并。
