## 一、地图：一本 1999 年的街道图

1999 年住在新加坡的人，家里车里多半有一本厚厚的**街道图册**：封面印着全岛，里面一页一格，后面是几十页的地名索引，大家说「在第几页第几格」。霏微的地图照这个做，画面仍是纸上的测绘图（细线、方格、纸色、扫描带），但比现在真得多。

### 缩放

用两指或滚轮连续缩放，纸面跟着推近，**像真实地图一样一级一级显出更多东西**：

| 缩放 | 看得见的 |
| --- | --- |
| 全岛 | 海岸线、五片底色、五片和主要新镇的名字、地铁两条线、快速公路、大的水库和山 |
| 一片 | 52 个区的区界和区名、地铁站、巴士总站、河、主要道路 |
| 一区 | 区块名、路名、地标编号、巴刹和熟食中心、公园、学校（虚构名）、档案钉 |
| 街区 | 组屋一座一座的轮廓和座号、店屋排、巴士站 |

- 点一个区，旁边滑出区卡（邮区号、区块、档案数、去区页）。
- 页角是街道图式的**页码和格号**（如「第 12 页 C3」），缩放时跟着变。日报、档案以后可以直接写「见街道图第 12 页 C3」。
- 手机竖屏：两指缩放，单指拖动；默认先看全岛。
- 减少动态效果时，缩放不带惯性和弹簧。

### 图层

海（纸色网点）· 填海前的海岸（**红虚线**）· 1999 年的海岸线 · 填海地（浅一层、细斜线）· 河、水库 · 山（等高线）· 保护林 · 组屋区（灰网点）· 工业区（细格）· 机场跑道 · **未测绘**（空白斜线）· 快速公路（双线）· 主要道路 · 铁路（黑白相间）· 废弃支线 · 地铁南北线（红）、东西线（绿）· 轻轨（灰，十一月六日前画成虚线）· 在挖的东北线（铅笔虚线）· 渡轮、缆车 · 区界 · 地名、站名、地标编号 · 档案钉

### 形状从哪来

**参考 OpenStreetMap**（作者定，「全部原创」规矩之外的新例外）。海岸线、河道、主要道路、组屋轮廓照 OpenStreetMap 的真实形状，重画成我们自己的简化线条，存成我们自己的坐标数据，不放它的图块或图片。页脚加一行「地图参考 © OpenStreetMap 贡献者」；从它派生的坐标文件按 ODbL 注明出处。OpenStreetMap 的服务器从这里连不上，用 GitHub 上整理好的新加坡数据（例如 railrouter-sg 的铁路线）。现在的形状是 2020 年代的，要按 1999 年改回去：裕廊岛还没连上，樟宜和大士的填海没那么大，滨海湾还是海。描完我截图给作者对着现实看，哪里不像就改哪里。

## 二、网站怎么改

- **区的数据**放进 `src/data/gerimis/`：52 个区（编号、中英名、片、种类、邮区号、边界、简介、登记时的一句话、区块、地标、车站、时钟差）；地图的几何数据另存，构建时裁成几级。
- **现有七个区**改名（对照表在地名录第一节），档案里的地名跟着改，旧网址 `/district/pons-ruber/` 这些自动带到新区。CLAUDE.md 的区名单一起改。
- **档案**：照旧只填 `district`；新增可选字段 `block`（区块），写了就钉到区块上。
- **区页**：区图（那一区推近的样子）、区块、地标、交通、邮区号、档案。未测绘的区没有区页。
- **地图页**：重做成可缩放的街道图。
- **入馆登记**选住处：先选片，再选区，只列 35 个居住区；地图上点也行。
- **办公室幻灯片**：每区一盘不变，区图换新的。
- **不碰**：资料室和日报（另一个对话在改）。日报题库、网点照片场景等区定了再扩。

## 四、还能往外长什么

都是读现有数据自动生成，作者不用为每份档案多做事：

- **地名索引**：街道图后面那几十页。按拼音 / 字母排的地名、路名、站名、区块，点一下地图飞过去。朋友想写外婆家楼下，先在索引里找到那条路。
- **组屋座号和邮编**：缩到最近，每座组屋有座号；每座一个六位邮编（照原型的邮编规则编）。档案里写「实龙岗 7 座」就能钉到那一座；以后居民登记抽到的单位、前任住户的信，地址都从这里来。
- **地图的旧版**：定稿地图下面压着两三张旧版（七十年代、五十年代），掀开看那时的海岸线、甘榜、老游乐场、跑马场。和档案的「旧稿」是同一种纸面读法。
- **地铁线路图**：一张 1999 年的车站线路图海报（两条线一条轻轨），东北线画成「建设中」。
- **巴士总站的路线牌**：每个总站一块牌子，列出从这里开的几路车和终点（先只列，不做路线规划）。
- **记忆钉**（以后有后端再做）：居民在地图上钉一个点，写一句「我记得这里」。
