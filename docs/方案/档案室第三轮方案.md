# 档案室 · 第三轮方案（2026-10-08）

> **状态（2026-10-12 搬进仓库时注）**：已做完（#60）。
>
> 原件在 claude.ai 项目文件夹 `ideas/霏微-档案室第三轮方案.md`，以后只改仓库里这份。

YosH 提的三件事：拿到桌上没有动画，而且桌上读也是弹出一张放大的纸；桌子中间那盏验档灯看不出有什么用；就地翻阅时飞出来的文件夹画得太潦草。

## 原因（查代码得出）

- 「拿到桌上」时，代码只是把档案从抽屉列表里删掉，再在桌面上直接摆一个封面（`stacks.ts` 的 `toTable` → `room.setTable`）。镜头还停在抽屉前，没有拿起来走过去的过程。
- 桌上读和就地翻看用的是同一张弹出的纸，房间被压暗在后面，所以看起来就是「放大看」，和档案在不在桌上没有关系。
- 验档灯只在读档时才亮。可是一读档，纸就盖住了整张桌子，灯亮了也看不见。不读的时候它又一直关着。
- 飞出来的封面只有底色、一条色带、一个标题框和一个印章，三类档案除了颜色以外一模一样。

## 改法

1. **拿到桌上，真的拿过去。** 档案从抽屉里升起来，被拿着走过房间，落在桌上它的位置，抽屉在身后关上。镜头跟着走到桌边，落下时有一声。
2. **桌上读，就是坐下来读。** 点桌上一份，镜头像人坐到椅子上一样，俯身对着面前的吸墨垫。档案从桌上的位置滑到面前，封面在 3D 里翻开，纸摊在垫子上。字要看得清，靠的是人凑近，而不是弹出一张纸。纸的四周还能看见桌子：两边的黄铜台灯、上方的验档灯、放大镜、铅笔。房间不压暗。
3. **验档灯有用、看得见。** 坐下读 SECRET 以上的档案时，正前方那根灯管会闪几下亮起来，亮在纸的上沿，冷光照在纸上。平时也能点它自己开关，和台灯一样有拉绳。
4. **就地翻阅的文件夹按类别重画**，全部从现有字段自动生成，作者什么都不用加：
   - **人员**：马尼拉夹，像人事卡。正面印「人员档案」表头，打字填写编号、姓名、区、日期，右上角有照片位和回形针，左边两个装订孔。
   - **事件**：立式牛皮纸档案袋。正面印红色案卷表格，「卷内目录」按附件一件件列出，袋口有绕线扣。
   - **计划**：硬皮卷宗。布脊、书脊上贴标签，封面压印表格。
   - **TOP SECRET**：绕线档案袋（两颗垫圈 + 线），开袋要先把线绕开。
   - 封面翻开前，先在抽屉里升起一点再飞向你，而不是凭空出现。
5. 「减少动态效果」时，这些都换成淡入淡出。

## 要你定的一件事

桌上读要不要改成「坐下来读」？

- **坐下来读**（推荐）：凑近看，桌子和灯都在画面里，验档灯也就看得见了。
- **保留弹出的纸**：只补上拿过去和落桌的动画，读的方式不变。
