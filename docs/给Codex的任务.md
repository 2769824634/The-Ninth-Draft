# 给 Codex 的任务

Codex 只做这里列出、而且**作者点过头**的任务（状态写「可以开工」的）。做之前先读 `AGENTS.md`。每条一个分支、一个 PR，分支名 `codex/<几个英文词>`。

维护：作者或 Claude 往下加任务；Codex 开工时把状态改成「进行中（PR #N）」，合并后改成「完成」。

2026-10-12 先列了几条候选，**都还没经作者同意**。

---

### 1. 日报平常日子的题库扩充

- 状态：候选，等作者点头
- 现在：日报平常日子的文字来自 `src/lib/daily.ts` 里的几个固定题库（`QUIET` 平常新闻、`BUSES` 巴士改道、`LETTERS` 读者来信、`EVENTS` 活动、`FILMS` 戏院、`OFFICE`、`WEATHER` / `DRY` 天气、`CLASSIFIEDS` 分类广告），量少，一年里会重复。
- 要做：每个题库加到够一年不明显重复，中英各写一份，不互相硬翻。先交一个题库（建议 `QUIET`）的 30 条给作者看语气，过了再铺开。
- 要求：每条是一件完整的事（时间、地点、谁、要大家做什么）；地名只用 `src/data/gerimis/districts.ts` 里有的；现实新加坡细节先查、留出处（写在 PR 描述里）；1999 年还没有的东西不写（见 `docs/作者的规矩.md` 容易写错的列表）。怪事不放进平常新闻。
- 不碰：`buildIssues` 的逻辑、档案生成的新闻和更正栏（那部分在 PR #88 刚改过）。

### 2. 楼下告示板的告示题库

- 状态：候选，等作者点头
- 现在：「我家」楼下告示板每周两三张（寻猫、停水洗水箱、喷药防蚊、卡拉 OK 晚会等），题库在 `src/app/visitor/households.ts` 里。
- 要做：加种类、加条数；每张有标题、时间地点、要大家做什么、谁贴的。中英两份。
- 不碰：住户生成、前任住户的信、暗线（`P`、登记事项核对）。

### 3. 设定补充：各区的小事

- 状态：候选，等作者点头
- 要做：给 35 个住人的区各写几条「这一区大家都知道的事」（哪个巴刹几点最挤、哪条巴士总是迟），写进 `docs/设定/设定补充.md`，作者点头后再决定放进哪里。
- 要求：每条现实细节附出处，查不到的标「凭记忆，未核对」。
