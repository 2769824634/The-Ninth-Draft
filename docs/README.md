# docs · 目录

这个目录让任何人（作者、Claude 的两个账号、Codex）只看仓库就能接着干活。2026-10-12 建立。

## 先读什么

第一次来按这个顺序读：

1. `../CLAUDE.md`：设计决定的总账，作者拍板的事。
2. [作者的规矩.md](作者的规矩.md)：作者的工作规矩和习惯（怎么交付、文字怎么写、真实细节先查）。
3. [进度.md](进度.md)：做到哪了、谁在改什么、待作者定的事、全部 PR 记录。
4. [协作.md](协作.md)：两个 Claude 账号和 Codex 怎么分工、怎么不撞车、自动检查查什么。
5. [技术笔记.md](技术笔记.md)：踩过的坑和代码地图。
6. 要写岛上的内容时：[设定/](设定/README.md)。

Codex 还要读 `../AGENTS.md` 和 [给Codex的任务.md](给Codex的任务.md)。
