## 格式

- 每本一个 `.md`，开头的 frontmatter 已按仓库 `src/content/books` 的字段写好（title / titleAlt / author / authorAlt / year / lang / source / order），可以直接放进去。
- `##` 是章（或一篇），`###` 是章里的小节（罗马数字、卷里的单篇）。诗用行尾 `\` 换行，空行分节。
- 古腾堡的页眉、许可证、制作者署名都已去掉；维基文库的导航、校勘注、版本说明也去掉了。
- 中文用维基文库自带的繁简转换取简体。转换偶尔会出错，比如《呼兰河传》第一章里学生讲「乾菜的乾」那段，简体后两个字都成了「干」。上架前想要繁体原貌的话，`tools/` 里改一个参数就能重抓。
- `tools/` 是抓取和清理用的脚本，重跑用，不是书。
