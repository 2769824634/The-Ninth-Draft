## 一、咖啡店点单

顺序是：饮料 → 奶 → 糖 → 浓淡 → 冷热。例如 kopi C kosong gao peng，就是冰的、浓的、加淡奶、不加糖的咖啡。【已查】

| 说法 | 意思 | 核实 |
| --- | --- | --- |
| kopi（咖啡） | 默认加炼奶和糖 | 已查 |
| teh（茶） | 福建话 / 潮州话的「茶」，默认也加炼奶和糖 | 已查 |
| O（乌） | 不加奶，黑的。福建话「乌」 | 已查 |
| C / Si | 加淡奶（常说 C 来自 Carnation 牌淡奶；Si 来自海南话「鲜」） | 已查 |
| kosong | 不加糖（马来语「空」） | 已查 |
| siew dai（少甜） | 少糖，可能出自广东话 | 已查 |
| gah dai / ka dai | 多糖 | 已查 |
| gao / gau（厚） | 浓 | 已查 |
| poh（薄） | 淡、多兑水 | 已查 |
| di lo | 不兑水，最浓 | 已查 |
| peng（冰） | 加冰 | 已查 |
| 半烧 ban shao | 半热，温的 | 已查 |
| 「要烧的还是冰的？」 | 烧 = 热（福建话 sio） | 作者听过；福建话「烧」作「热」解属常识，新加坡咖啡店用法我没查到书面出处 |
| tak kiu | 美禄（Milo） | 凭记忆 |
| 打包 / tapao | 外带 | 凭记忆 |

| 东西 | 1999 年的情况 | 核实 |
