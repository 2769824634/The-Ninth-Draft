# 设定补充（提议区）

`CLAUDE.md` 只有作者能拍板。Codex、或者任何不确定能不能改 `CLAUDE.md` 的人，想**新增或改动设定**时写在这里，在 PR 描述里说明。作者点头后，由 Claude 并进 `CLAUDE.md` 或 `docs/设定/` 里对应的文件，再把这一条标成「已并入」。

只写设定（岛上有什么、规矩怎么定）。界面文字、日报内容这类「照设定写出来的东西」直接改对应的数据文件，不用先在这里提。

## 格式

每条一个三级标题，照这个填：

```
### 2026-10-12 · 提议人 · 一句话标题

- 状态：待定 / 已并入（PR #NN）/ 不采用（作者原话）
- 想加或改什么：
- 为什么：
- 和 CLAUDE.md 哪一条有关、有没有冲突：
- 牵涉真实新加坡的细节：每条附出处链接；查不到的写「凭记忆，未核对」
- 会影响哪些文件或页面：
```
