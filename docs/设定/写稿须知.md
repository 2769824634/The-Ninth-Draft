# 雨洲 · 写稿须知（给朋友）

> **状态（2026-10-12）**：照 2026-10-05 的旧版「入馆须知（给朋友）」改写，换成了现在的设定（52 个区、新口号、怪事三成、都市传说的边界）。**作者还没审这一版**，发给朋友前请作者看一遍。
>
> 写给不懂技术的朋友。他们把稿子发给 YosH，由 YosH 或 Claude 整理成档案文件。档案文件的格式（frontmatter、修订痕迹、附件）写在仓库 `README.md`「添加 / 修改档案」一节，朋友不用看。

欢迎来到 **Ashmere / 雨洲**。这是一座海峡里的小岛，时间永远停在 1999 年，日子和现实的新加坡同一天。你不需要懂任何设定，只要写一小段自己记得的事，就是这座岛的一部分。

## 一、这座岛一句话

一座由大家真实记忆拼成的城市。现实里被划掉的东西（拆掉的老店、改了线的巴士、外婆家楼下），在雨洲被留下来，而且会回来。

岛上有个很普通的政府部门叫 **记录署（Records Office）**，负责把发生过的事整理归档。档案改过以后，现实跟着变；被划掉的旧东西有时会漏回来，叫做 **回流（Backflow）**：路牌挂回旧名，拆掉的店一夜亮灯，早就改线的巴士半夜还停在旧站。

岛上的口号：**「本岛一切如常。如有不同，以现场为准。」**

## 二、写哪里

地理照 1999 年的新加坡，分成 52 个区，用当地真名：宏茂桥、大巴窑、红山、后港、兀兰、实龙岗、勿洛、裕廊西……你记得的地方，在岛上多半就是同一个名字。少数带政治人物名字的地方换成了当地旧名。查不到就照你记得的写，我们来对。

全部区名和片区在 `docs/设定/地名录.md`。

## 三、写什么

三种档案，随便挑一种，也可以只写一小段：

- **人员**：岛上的一个人。可以是你编的邻居、同事、亲戚。
- **事件**：某一天某个地方发生的事。大多数是普通的事，也可以是一件说不清的怪事。
- **计划**：署里的一项工程、制度或规定，越官腔越好。

大约七成是普通日子，三成是怪事。怪事从熟悉的日常里长出来：你天天走的那条路，某天多了一个站牌。

不用写完整，写不下去的地方，就让它被「涂黑」。

岛上已经有十来个常露面的人（楼下的莲姨、卖鱼圆面的阿成、邮差拉欣大叔等，见 `docs/设定/常露面的人.md`），可以直接让他们出场。

## 四、语气

- 像真人说话，第一次来的人也读得懂。幽默、讽刺建立在这上面，不为抖机灵而抖机灵。
- 日常的、一本正经的，有一点不对劲。要的是「怪」，不是「恐怖」，不血腥。
- 可以像官方文件那样说话，但里面藏着人的小脾气。例：「请市民不要向路牌核实路牌。」
- 都市传说写成传闻：楼下阿姨顺口讲的、读者来信里问的，没人证实，也不解释。

## 五、红线

1. 不写现实中的政治人物、政党、政府决策，以及真实的敏感事件（真实案件、真实灾难、真实死者）。只借地名和年代，人和机构都是虚构的。
2. 宗教场所只写外观，不写成鬼屋。军事用地不写里面有什么。不针对任何族群。
3. 不写会让人对上现实中某个人的私事。名字可以用真名、昵称或代号。
4. 不写违法、歧视和攻击别人的内容。
5. 店、品牌、公司换成岛上虚构的那一家（真店名换成岛上虚构的店名，地名照用真名）。

## 六、语言

中文、英文都可以，写你顺手的那一种。另一种语言由我们补。

## 七、怎么交稿

照下面的格式填空，发给 YosH 就行，不需要任何技术：

```
类别：人员 / 事件 / 计划
标题：
副标题：（一句话说明身份或事由）
署名：真名 / 昵称 / 代号（随意）
日期：（1900–1999 年的任何一天）
地点：（区名，能写到哪条街、哪一座组屋更好）
正文：

相关的档案：（想连上别人的，写编号，不知道就空着）
```

写在 1999 年某一天的档案，到了岛上那一天（也就是现实里同一个月同一天）才会出现在网站上。

## 八、一个可选的小暗号

如果你写的是回流的怪事，日期尽量落在某个月的 **9 号**。不用向读者解释，让细心的人自己发现。
