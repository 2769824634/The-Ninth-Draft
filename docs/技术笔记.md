# 技术笔记

给接手写代码的人（Claude 第二个账号、Codex）。这些是之前踩过的坑和代码地图，以前只在第一个账号的项目记忆里。截图和检查模式的用法在 `CLAUDE.md`「检查与截图」，功能说明在 `README.md`，这里不重复。

## 构建和检查

- 检查用 `npm run build`。`astro check` 在 TypeScript 7 下跑不起来，不用它。
- 干净构建大约一分钟，大部分时间在裁剪、切块中文字体（`integrations/zh-fonts.mjs`）。
- 云端会话开机时 `.claude/hooks/session-start.sh` 会自动 `npm install` 并在后台构建，锁文件 `/tmp/n9-build.lock`，日志 `/tmp/n9-build.log`。
- 推到 `main` 会自动部署到 GitHub Pages（`.github/workflows/deploy.yml`，用 `withastro/action`）。所以 `main` 永远只通过 PR 改。
- 每个 PR 自动跑 `.github/workflows/check.yml`：构建 + `scripts/check-rules.mjs`（规矩检查，规则在 `scripts/rules.json`，说明见 `docs/协作.md`）。本地也能跑：`node scripts/check-rules.mjs`（默认和 `origin/main` 比）。

## 无头浏览器（云端没有显卡）

- 3D 房间在云端用软件渲染，大约每秒一帧甚至更慢。弹簧动画看起来像坏了，其实只是慢。帧间隔被限制在 0.1 秒，所以弹簧要比平时多等十倍时间。
- 拍最终状态时用 `reducedMotion: 'reduce'`，镜头直接跳到目标，不用等动画。资料室取书、档案室开档不这样会一直停在半路。
- `sessionStorage` 里设 `n9:boot=1` 可以跳过开机封面（检查模式 `?check` 已经自动跳过）。
- 要快速改来改去，另开一个端口跑 `astro dev`，比反复构建快。
- 手机尺寸 390×844，电脑 1440×900。像素比 2 的截图在软件渲染下很慢，截图超时要放宽。
- Playwright 的 `setFiles` 碰到非 ASCII 文件路径会悄悄失败，先复制成英文文件名。
- 旧稿掀角用 `requestAnimationFrame`；想定格某一帧，可以把源码里含 `clipPath` 的那个 rAF 回调拦下来。
- **不要用 `pkill -f` / `pgrep -f` 搭配一个也出现在同一条命令里的字符串**，会把当前 shell 自己杀掉。
- 夜间模式下档案室页头字变深，是无头浏览器里 CSS 过渡卡住的假象，不是真 bug。

## 网络

- 云端的代理挡住了 OpenStreetMap 的服务器；`raw.githubusercontent.com` 能用。地图数据是从 Overture（S3 区段读取）取的：`scripts/map/fetch.py` 下载到 `.cache/map-src/`，`scripts/map/build.py` 按 1999 年改回去，输出 `public/map/base.json`、`public/map/detail.json`、`src/data/gerimis/sheet.ts`。说明在 `scripts/map/README.md`。
- 贴图来源 ambientCG、Poly Haven 的下载域名在云端允许列表里。

## 存在访客本机的东西

都以 `n9:` 开头（`localStorage` / `sessionStorage`），自带盘带在 IndexedDB `n9-reels`。改它们的格式时要兼容老访客已经存下的数据，例如：`n9:visitor`（登记）、`n9:table`（阅档桌上的档案）、`n9:prefs`（灯、声音等偏好）、`n9:diary`（私人日记，永远不上传）。

## 档案文件

格式、修订标记、附件写法在 `README.md`「添加 / 修改档案」。要点：

- `src/content/records/<类别>/<编号>.md` 是英文主文件，`<编号>.zh.md` 是中文版。
- 写成 1999 年某一天的档案，到岛上那一天才出现；旧稿 `drafts` 每一稿也按自己的日期出现。
- 回流事件日期尽量落在某月 9 号。
